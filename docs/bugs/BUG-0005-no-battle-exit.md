# BUG-0005：进入战斗后无法退出

## 严重性

S1：玩家只能强制关闭游戏，可能误以为存档损坏。

## 影响版本

- 报告版本：v0.7.0 / v0.9.0 构建
- 修复版本：v0.9.1

## 复现

1. 从路线节点进入任意战斗。
2. 查找返回、退出或投降入口。

## 实际

战斗页面没有可用的退出/投降入口。

## 期望

- 提供“投降并返回最近检查点”。
- 二次确认，明确未确认奖励不会发放。
- 返回后保留最后一个安全检查点，不恢复战斗中间态。

## 回归

- 普通战斗、精英战、首领战、挑战战斗均能退出。
- 重复点击不会重复写档。
- 退出后继续游戏恢复到正确节点。

当前状态：实现通过。战斗页已有“退出战斗”按钮、确认对话框和返回标题检查点路径；v0.9.1 回归验证确认信号只发出一次。
最终状态：已关闭。
