# BUG-0007：战斗反馈只有文字，卡牌功能不可见

## 严重性

S2：战斗信息不足，玩家必须记忆牌组页说明。

## 修复要求

- 手牌显示完整效果摘要、目标、费用和等级。
- 点击/悬停显示详情，包括升级前后变化。
- 出牌后显示卡牌飞入、目标高亮、伤害数字或状态提示。
- 受击时生命条、护盾和数字变化清晰可见。
- 战斗日志按玩家行动、敌人行动、状态变化和压力分类。

## 回归

- 伤害、治疗、护盾、抽牌、灵性、标记、削弱、风险、意图揭示均有可见反馈。
- UI 不重新计算规则，只显示命令结果与事件。

当前状态：实现通过专项检查。手牌显示效果摘要；卡牌飞出、伤害数字、治疗/护盾变化和状态/污染提示已接入事件反馈。
最终状态：已关闭。
