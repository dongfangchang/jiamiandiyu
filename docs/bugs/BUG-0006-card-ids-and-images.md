# BUG-0006：战斗手牌显示英文 ID 与空图像

## 严重性

S1：玩家无法辨认手牌，战斗不可正常理解。

## 影响版本

- 报告版本：v0.7.0 / v0.9.0 构建
- 修复版本：v0.9.1

## 证据

用户截图显示 `lantern step`、`warding circle`、`coffin nail`，图像区域显示“灵界残留”。

## 实际

战斗只按旧遭遇牌表注入中文名与图片，玩家自定义牌组中的 v0.7 新卡无法解析。

## 期望

- 战斗按当前已确认牌组解析中文名、完整效果、图像和等级。
- 找不到资源时使用明确中文占位，不能暴露内部 ID。

## 回归

- 16 张卡逐一进入战斗手牌。
- 抽卡、升级和牌组界面与战斗使用同一显示信息。

当前状态：实现通过。战斗显示信息改为从当前牌组、手牌快照和正式内容解析，16 张卡共用同一资源映射；截图已不再出现英文内部 ID。
最终状态：已关闭。
