# BUG-0022：已拥有的序列锁定卡牌被提示为可加入

- 版本：v0.30.1
- 严重度：S2
- 状态：已修复，牌组玩法 287 项和 UI 64 项通过

## 症状与复现

在序列 9 档案打开牌组页，收藏有提灯步且牌组未满。卡牌显示“已拥有 · 可加入”，点击后底部出现 `sequence_locked`。

## 根因与影响

玩法加入命令已校验序列，但 UI 用拥有状态代表可加入状态，且中文原因映射缺少序列锁定。影响所有已拥有但当前序列不可使用的卡牌，不是只有提灯步。

## 修复策略与验收

玩法快照提供可加入与锁定原因，UI 消费结果并说明所需序列，禁止用放宽序列限制消除报错。回归覆盖已拥有但锁定、合法卡、移除已入组卡及直接非法命令。实际通过记录待负责人补充。
