# BUG-0010：主档损坏时有效备份无法恢复

## 严重性

S2：存档恢复路径失效，可能让玩家失去最后一次可恢复进度。

## 复现

1. 写入两份有效检查点，形成主档与 `.bak`。
2. 把主档改为非法 JSON。
3. 点击“恢复上次备份”。

## 根因

恢复函数调用普通 `save_slot`。该函数在覆盖前把当前损坏主档复制为备份，随后备份校验失败并中止，于是真正的有效备份被破坏或无法使用。

## 修复

新增专用恢复事务：校验备份、写临时档、校验临时档、移开旧主档、提交恢复档；失败时尝试恢复旧主档，并保留 `checkpoint.restore-old.json`。

## 回归

- 主档损坏且备份有效时可恢复。
- 恢复后的主档可读取。
- 损坏原件被保留供诊断。

状态：已关闭。
