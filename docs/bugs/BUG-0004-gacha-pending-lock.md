# BUG-0004：抽卡后 pending 卡死且无法退出

## 严重性

S1：核心成长流程中断，玩家只能强制关闭程序。

## 影响版本

- 报告版本：v0.7.0 / v0.9.0 构建
- 修复版本：v0.9.1

## 复现

1. 进入灵界祈愿。
2. 执行单抽或三连。
3. 等待结果出现。
4. 尝试继续抽卡或点击返回。

## 实际

- pending 状态可能不恢复。
- 按钮持续不可用或界面内容不刷新。
- 无法通过界面返回白昼档案。

## 期望

- 每次请求无论成功、失败还是异常均恢复 pending。
- 结果区立即刷新。
- 返回按钮在请求结束后始终可用。
- 出错提供原因并允许重试。

## 根因状态

修复已实现并通过 v0.9.1 专项回归：

- 抽取请求使用 pending token。
- 成功、失败和 4 秒超时都会恢复按钮。
- 返回按钮在 pending 时仍可用。
- 退出会清除 pending，不等待后台请求。

## 回归

- 单抽成功、三连成功、券不足、规则拒绝、连续两次抽取。
- 抽取后返回主 hub。
- headless UI smoke 和实际窗口都要覆盖。

当前状态：已关闭，完整 QA 通过。
