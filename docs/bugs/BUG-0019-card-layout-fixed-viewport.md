# BUG-0019：卡牌在较小窗口或缩放后仍被截断

## 严重性

S1：手牌操作入口可能离开可视区，影响完整战斗流程。

## 根因

- 战斗页面没有在固定 1600×900 之外提供布局降级。
- 手牌区与卡片依赖固定最小高度。
- 非全屏窗口没有限制在桌面可用区。

## 修复

- 增加完整页面双向滚动兜底。
- 自动聚焦并滚动到控件。
- 窗口非全屏时 clamp 到可用桌面。
- 保留整卡点击和按钮操作。

## 回归

`V014_CARD_LAYOUT_OK checks=20`，覆盖 1600×900、1366×768、1333×750、1280×720。

状态：已关闭。
