# BUG-0024：牌组页面部分中文显示为方框

- 版本：v0.30.1
- 严重度：S2（影响规则说明阅读）
- 状态：已修复，900 个汉字覆盖和 macOS OpenGL 实际渲染验证通过

## 症状与复现

用户截图中，同一页面部分中文正常，而卡牌目标“敌方”和预设说明中部分字显示缺字符号。检查平台字体回退、字符覆盖与源文本编码后再确定修复，不能仅凭截图宣称文本编码损坏。

## 修复策略与验收

font_deck_fix 已复现系统字体没有正确匹配简体中文：显式请求 PingFang SC 仍选择 PingFang HK，“敌”“稳”的 `has_char` 检查失败。修复共用主题字体策略，采用带许可的完整 Noto 简体字库并记录固定来源与哈希。验证截图相关汉字及界面常用字符覆盖，并检查真实窗口。保持原始正常中文，不用近义字替换掩盖字体问题。最终通过记录待 font_deck_fix 交付。
