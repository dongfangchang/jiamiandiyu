# BUG-0036：手牌框 / 选择按钮被裁出 1600×900 视口

## 严重性

S1：手牌看得见，但底部卡框与「选择手牌」被裁切，操作入口不可达。

## 复现

1. 1600×900 进入战斗。
2. 查看手牌区底部：卡框下缘与选择按钮在折线以下。
3. `V014_CARD_LAYOUT` 在修复前于 1600×900 失败。

## 根因

1. `BattlePageContent` 用普通 `Control` 固定 900 高，不向上汇报子布局最小高度；中段（情报+敌列）实际最小高度被抬高后，手牌区仍按满高绘制，画出视口，而滚动条仍认为「刚好放下」。
2. 手牌 `HBoxContainer` 默认纵向拉伸，卡片被拉高，选择按钮跟着沉到折线以下。

## 修复

- 页面内容改为 `MarginContainer`，最小高度可随子项上报；中段/页头/状态条设硬上限。
- 手牌卡片 `SIZE_SHRINK_BEGIN`，固定 `HAND_CARD_SIZE`，不再纵向拉伸。
- 压缩中段/手牌预算，保证 1600×900 无需翻页即可点到选择按钮。

## 回归

- `V014_CARD_LAYOUT_OK`
- `V025_VIEWPORT_GUIDANCE_OK`

状态：已关闭（v0.51.0）。
