# BUG-0017：连携终局事件与实际结算不一致

## 严重性

S3：非阻断，但回响事件可能声明未执行的效果。

## 复现

- 先打两张付费牌，再用第三张伤害牌直接击杀最后敌人。
- 旧实现发出回响事件，但因战斗结束跳过回响抽牌和回灵。

## 根因

连携在卡牌效果结算后、最终胜负检查前推进；回响伤害击杀全部敌人时又提前返回。

## 修复

- 卡牌终局检查先于连携推进。
- 回响完成伤害、回灵和抽牌后再做最终胜负检查。
- 正式 balance schema 强制校验 `combat.chain`。

## 回归

`V0100_CHAIN_OK checks=34`，覆盖直接击杀、回响击杀、拒绝命令、重洗和手牌上限。
