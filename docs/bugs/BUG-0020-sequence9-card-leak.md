# BUG-0020：序列9可提前使用序列8卡牌

## 症状

序列9默认牌组和部分预设包含“序列9→8”或“序列8·小丑”卡牌，祈愿池也可能在晋升前抽到这些卡牌，造成能力进度提前。

## 根因

牌组校验和祈愿抽取只校验卡牌存在与拥有状态，没有读取 `sequence_band`；默认预设沿用了早期混合测试内容。

## 修复

- 序列9牌组拒绝序列8及过渡卡，并返回 `sequence_locked`。
- 祈愿按当前序列过滤序列8卡牌。
- 默认四套预设收敛为序列9占卜家能力。
- 晋升后刷新牌组序列门，解除合法的过渡卡锁定。

## 回归

- `V028_POTION_DIGESTION_OK checks=35`
- `V07_DECK_TESTS_OK checks=274`
- `V07_DECK_TESTS_OK checks=270`
