# BUG-0035：弃置效果无法选手牌（冥想 / 安静发丝）

- 发现版本：v0.35.0
- 修复版本：v0.35.0
- 严重度：S2（策略选择被静默剥夺）

## 症状

打出「冥想」后弃置手牌，玩家无法选择弃哪一张；引擎直接弃掉手牌末张。

## 复现

1. 手牌同时有「冥想」与至少一张其他牌。
2. 打出「冥想」。
3. 另一张牌被自动弃掉，无选择 UI。

## 根因

`battle_engine` 的 `discard` 效果使用 `_hand.pop_back()`；文案“弃置1张手牌”在卡牌游戏语义下应为玩家选择。全卡池扫描后，无条件弃置仅两张：

- `card.skill.focus`（冥想）
- `card.skill.black_thread`（3-0611 安静发丝）

## 修复

- 命令增加 `discard_instance_ids`；打出前必须选满无条件弃置张数。
- 快照手牌带 `required_discard`；战斗 UI 进入“标记弃置”点选模式。
- 抽样机器人通过 `auto_discard_ids_for` 自动补齐选择。
