# BUG-0012：测试档案恢复槽位错配

## 严重性

S1：测试档案战斗退出后可能恢复普通档案，或者没有可继续的检查点。

## 根因

- 测试档案写入 `test_checkpoint`，控制器回标题后仍检查普通 `checkpoint`。
- 测试档案开局没有立即保存初始检查点。
- 标题页只按普通晋升状态判断挑战可用性。

## 修复

- 活动档案槽位随测试档案切换。
- 测试档案进入后立即保存初始检查点。
- 普通新游戏切回配置的基础槽位。
- 测试档案标题页显示挑战可用，挑战探针使用序列 8 测试状态。

## 回归

- 测试战斗退出后可继续恢复地图。
- `test_checkpoint` 可读取。
- 普通检查点字节未变化。
- 测试档案可进入挑战档案并打开修饰选择。

状态：已关闭。
