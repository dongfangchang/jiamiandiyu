# BUG-0015：Pending 页面仍会禁用返回或取消

## 严重性

S2：挑战、牌组、升级、路线和仪式在等待命令时可能把玩家锁在页面中。

## 复现

1. 对页面调用 `set_pending(true)`。
2. 尝试退出挑战、返回牌组、返回升级页、返回路线或取消仪式。
3. 旧实现中按钮禁用，处理函数也提前返回。

## 根因

导航操作错误地复用了“防止重复提交”的 busy 条件。重复结算需要拦截，但离开页面不应依赖领域结算完成。

## 修复

- 返回/退出/取消按钮不再受 pending 禁用。
- 这些导航回调不再因 busy 提前返回。
- 修改、开始、提交等会造成结算的动作仍禁止连点。

## 回归

`V093_PENDING_NAV_OK checks=10` 覆盖五个页面和单次意图发送。

状态：已关闭。
