# BUG-0009：测试通过但真实窗口阻断未进入发布门

## 严重性

S1 流程缺陷：自动化退出码为 0，但核心路径在真实窗口不可操作。

## 根因方向

现有测试偏重状态和信号级通过，缺少：

- 真实按钮点击后的 pending 恢复。
- 实际牌组中的全部卡牌显示解析。
- 战斗退出与返回检查点。
- 实际窗口截图和点击链路验收。

## 修复要求

- 增加发布前人工/自动化混合 QA 门。
- 自动化必须覆盖用户实际点击路径，而不仅是直接调用领域 API。
- 构建前必须关闭旧进程，重新导出唯一版本。
- QA 未签署时版本不得关闭或开始下一功能版本。
