# BUG-0023：再次进入祈愿页面重现旧抽卡结果

- 版本：v0.30.1
- 严重度：S2
- 状态：已修复，真实应用往返与历史快照隔离回归通过

## 症状与复现

完成抽卡，返回白昼档案，再进入祈愿页，仍展示上次抽到的卡牌。此前测试只验证当前页面返回后节点数量变为零，没有覆盖新建页面重新接收成长快照。

## 根因与影响

清理只修改旧 UI 的副本与节点。新页面 `apply_snapshot` 又读取持久化的 `last_gacha_results` 并渲染，使历史结算被当作本次展示。清空全局成长状态会误伤券、收藏、保底和存档，不是正确解决方案。

## 修复策略与验收

区分进入页面的资源快照与本次抽卡命令的展示结果；退出清理展示，命令完成后才能展示新结果。真实应用回归须覆盖抽卡→返回→重进→再次抽卡，并核对收藏、券与保底保持正确，存档恢复不重播历史结果。
