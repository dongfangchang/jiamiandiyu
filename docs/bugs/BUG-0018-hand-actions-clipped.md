# BUG-0018：手牌操作按钮被裁出窗口

## 严重性

S1：玩家能看到手牌，但无法找到或点击选择入口，形成“无法出牌”。

## 复现

1. 进入雨夜双影。
2. 打出两张牌或结束回合。
3. 手牌卡片底部按钮不可见，点击卡面没有反应。

## 根因

- 手牌卡片固定最小高度 244，大于手牌区实际可用高度。
- 只有底部小按钮绑定选择命令，卡图、卡名和整卡面板不可点击。
- 卡面 tooltip 暴露内部实例 ID，进一步干扰操作。

## 修复

- 卡片高度压缩至 212。
- 整张卡片接入鼠标选择。
- 选择后立即刷新卡框和“已选择”文字。
- 移除内部实例 ID tooltip。
- 增加实际鼠标、目标选择和打出命令回归。

## 回归

`V011_STATUS_KEYWORD_OK checks=8`。

状态：已关闭。
