# v0.34.0 廷根档案：气质统一与策略成型

- 日期：2026-11-10
- 状态：有条件关闭（2026-11-11）
- 前一版本：`v0.33.0`（验证中薄改动并入本版信息分层，不再单独叙事为大版本）
- 关闭说明：UI 减负 / 去下拉 / 普通遭遇加压与回归已交付；悬停可发现性并入 `v0.35.0` 桌面手感验收。

## 1. 用户价值

玩家打开主页面应像在翻值夜者档案，而不是操作桌面软件；打廷根时应能形成构筑与节奏策略，而不是被说明书式文字淹没。

## 2. 必须交付

1. **信息分层**：默认屏只留决策信息；出处、适合/慎用、长说明进详情或旁注。
2. **去系统控件**：主路径替换 `OptionButton`（牌组筛选、祈愿历史）为档案页签/蜡封条控件。
3. **策略可读**：联动以进度格表达“差哪一张”；预设只留策略钩子一句；情报条缩短为可扫读。
4. **回归**：布局不挤压专项、抽卡重进、价值审计、牌组引导合同仍通过。

## 3. 明确非目标

- 不解冻小丑技能包、不开放第二途径/贝克兰德。
- 不重做 40 张价值单位表。
- 不把独立构建/正式立绘作为本版关门前置（可进候选）。

## 4. 角色

| 角色 | 任务 |
|---|---|
| 产品经理 | 开版与关闭口径 |
| UI | 控件气质、减负、战斗/牌组/祈愿页 |
| 玩法 | 仅当策略表达需要快照字段微调 |
| 数值 | 普通遭遇轻度加压（临时写入 `data/enemies/v0.7.0/enemies.json` 战斗数值字段） |
| 主协调者 | 回归与版本号 |

## 5. 验收

- 主路径无原生下拉框。
- 预设卡默认不超过“名称 + 标签 + 一句钩子 + 费用摘要”。
- 联动行以短名 + 进度徽章为主，长出处仅 tooltip。
- 普通遭遇相对 v0.32 有可感知加压，且关键抽样不全线崩盘。
- 既有关键自动化绿。
- 关版前：真人试玩确认悬停可发现性。
