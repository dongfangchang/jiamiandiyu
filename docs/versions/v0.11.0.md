# v0.11.0 双路线与战斗操作可读性

## 1. 版本信息

- 日期：2026-11-08
- 状态：已关闭
- 类型：功能版本
- 主题：调查路线选择、整卡点击、状态关键词与战斗按钮可见性
- 用户价值：增加每局路线变化，并消除“看不见选择按钮/只能点小按钮”的操作阻断

## 2. 功能范围

### 调查路线选择

- 新游戏先进入路线选择，再进入白昼身份和牌组确认。
- 提供三条普通调查路线：
  - 廷根旧宅调查
  - 破碎游行
  - 镜廊巡夜
- 镜廊巡夜复用既有卡牌与敌人，但把休息和精英顺序提前，形成不同资源节奏。
- 路线 ID 写入检查点；继续游戏恢复原路线。
- 不新增第二途径或第二章节。

### 战斗操作修复

- 整张手牌卡片均可点击选择，不再要求点击卡片底部的小按钮。
- 手牌卡片高度从 244 压缩到 212，确保 1600×900 下底部按钮位于可视区。
- 选择状态立即更新卡框和“已选择”文字，不再要求等下一次快照重建。
- 移除卡面上的内部实例 ID tooltip。
- 敌方列显示“标记 2”“削弱 1”等状态徽章。
- 卡牌详情解释“标记：下次受伤时附加等量伤害并消耗”。

## 3. 根因记录

用户报告“打两张牌后卡死、看不到选择手牌按钮”。实际状态机未死锁，根因是：

- 手牌区域可用高度小于卡片固定最小高度。
- 操作入口只有底部小按钮，按钮被裁切后整张卡仍无点击行为。
- 卡面 tooltip 暴露内部实例 ID，造成额外视觉干扰。

修复采用布局压缩、整卡点击、即时选择反馈，而非修改战斗状态机或回滚。
