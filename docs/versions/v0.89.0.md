## 1.1 用户裁决（2026-11-25）

- 渲染器：**Mobile**（ADR-0036 采纳，ADR-0035 被取代）。
- 挑战未解锁时：菜单中**显示为灰色，并写明原因**。
- 战斗手牌（BUG-0041）：**通过**，关闭。
- 标题页和日记页的画面：**仍然太简陋**，改了几版都不满意。→ ADR-0037"目标帧先行"：先出 3 个风格方向的概念图，用户选定并签字后再实现；画面类代码暂停。
- **2026-11-25 用户选定方向**：标题页用 A（油画暗室），日记页用 B（铜版插画书）。由此确立全局风格规则："油画的房间里，放着铜版画的纸"（ADR-0037 附录 A）。
- 用户要求：**其他所有界面也先出参考图，由用户拍板；全部定下来以后再做实现。**→ ART-KEY-03…（逐站位出 2–3 个方案）。
