# v0.12.0 身份差异与被动可读性

## 1. 版本信息

- 日期：2026-11-08
- 状态：已关闭
- 类型：玩法可读性版本
- 主题：让白昼身份对战前选择和战斗结果产生可理解差异
- 用户价值：身份不再只是文案，玩家能直接理解每个身份带来的战斗或局外收益

## 2. 实现范围

- 记者：进入路线时被注视 -1；每场战斗胜利额外获得 1 占卜券。
- 医生：进入路线时最大生命 +4。
- 守墓人：最大灵性 +1；重复回响额外获得 2 残页。
- 身份选择页和当前身份页显示“身份特性”。
- 守墓人的战斗修正由空对象变为 `max_spirit_bonus: 1`。
- 新增身份被动内容的 schema 必填字段 `passive_text_zh`。

## 3. 架构

- 身份被动仍由 `data/cards/v0.7.0/progression.json` 唯一定义。
- `ProgressionEngine` 输出只读 `passive_text_zh`。
- 战斗修正继续通过 `apply_battle_modifiers` 注入玩家初始状态。
- 不改存档 schema，不改卡牌池和路线数量。
