# v0.17.0 试玩引导与行动反馈

## 1. 版本信息

- 日期：2026-11-08
- 状态：已关闭
- 类型：可理解性与试玩体验
- 主题：让新玩家更快理解第一步行动，并让战斗页面持续告诉玩家下一步能做什么
- 前一版本：`v0.16.0`，已关闭；主操作按钮状态已统一

## 2. 长期路线位置

本版本是“先打磨核心循环，再扩展内容”路线的第一步：先收集可理解性问题，随后进入 v0.18 的牌组与数值平衡，完成稳定构筑后再评估第二途径或第二章节。

## 3. 范围

### 必须交付

- 重写首次引导，使其明确身份、牌组、选牌、目标、结束回合和成长之间的顺序。
- 战斗载入和空闲行动阶段显示来自快照的下一步行动提示。
- 保留已有事件、原因码和命令边界；UI 不计算规则。
- 补充 UI smoke 和 headless 回归证据。

### 明确非目标

- 不新增卡牌、敌人、路线、数值、抽卡概率或存档字段。
- 不修改 `src/core/**`、玩法状态机、数据 schema 或正式资源稳定 ID。
- 不引入联网、插件或第二途径/第二章节。

## 4. 角色任务

- 产品经理：维护长期路线和本版本验收。
- UI：修改 `src/ui/**` 与 UI 报告，实现引导和行动提示。
- 玩法/数据层：只读审查快照字段是否足够，不直接修改规则。
- QA：验证重复点击、非法阶段、空数据、窄视口和 headless 启动。
- 主协调者：集成、质量门、提交和推送。

## 5. 验收标准

1. 首次引导按顺序说明身份、八张牌组、选牌目标、结束回合和晋升。
2. 战斗初始快照在玩家行动阶段显示明确的可执行下一步。
3. 非玩家行动、处理中和完成状态不显示误导性的可执行提示。
4. `UI_SMOKE_OK`、`V014_CARD_LAYOUT_OK`、headless 启动和 `git diff --check` 通过。
5. 代码 diff 不包含玩法、数值、存档、schema 或公共契约修改。

## 6. 关闭条件

- UI 报告记录引导和行动提示审稿结论。
- QA 报告记录自动化和破坏性路径结果。
- 产品经理确认范围未漂移后关闭版本。

## 7. 关闭结论

- 首次引导已扩展为按行动顺序的六步说明。
- 战斗状态条已接入快照驱动的下一步提示。
- UI smoke、卡牌多视口、macOS headless 和格式检查全部通过。
- 本版本未修改玩法、数值、存档、schema 或公共契约。
