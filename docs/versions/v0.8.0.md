# v0.8.0 体验整合与首次游玩收口

## 1. 版本信息

- 日期：2026-11-08
- 状态：已关闭
- 主题：让现有玩法可理解、可恢复、可稳定独立运行
- 用户价值：减少首次进入时的迷茫，补齐设置、帮助、存档恢复和战斗信息，不继续扩张内容量

## 2. 版本目标

在不新增途径、章节或大规模卡池的前提下，完成以下体验：

```text
首次启动
  -> 简短新手引导
  -> 设置与帮助入口
  -> 身份 / 牌组 / 路线 / 战斗 / 成长
  -> 清晰的战斗反馈和错误恢复
  -> 存档备份与重新开始保护
  -> 独立 Windows 构建稳定运行
```

## 3. 必须交付

### 3.1 新手引导

- 首次启动显示可跳过的短引导，最多 5 个步骤。
- 解释身份、八卡牌组、战斗目标、污染/被注视、抽卡与升级。
- 引导不代打、不修改规则、不强制观看。
- 已读状态保存到本地；之后可从帮助菜单重新打开。

### 3.2 设置与帮助

- 窗口/全屏模式、界面缩放、减少闪烁、文字大小。
- 帮助页包含基础操作、术语表、存档位置和检查点语义。
- 设置保存、重启恢复和损坏设置回退。

### 3.3 存档管理

- 标题页显示主档、备份、保存时间和当前阶段。
- 提供备份恢复，并在覆盖当前进度前明确确认。
- 新游戏覆盖已有进度前要求二次确认。
- 损坏档显示诊断信息和原件保留状态，不自动覆盖。

### 3.4 战斗与成长可读性

- 卡牌详情显示费用、目标、效果、升级等级和下一等级变化。
- 战斗记录区分玩家行动、敌人行动、状态变化、压力与死亡。
- 非法操作、资源不足和 pending 原因保持稳定、可读。
- 不改变现有规则和数值平衡。

### 3.5 构建与质量

- 独立 Windows 构建在项目目录外启动，可完成新游戏、继续、设置和退出。
- 不依赖网络、编辑器、`.tools/` 或开发测试文件。
- 修复所有运行时错误日志；非致命资源缺失也不得残留。
- README 说明构建运行、存档目录、备份恢复和开发启动区别。

## 4. 角色任务

### UI

- 新手引导覆盖层、设置页、帮助页、存档管理页。
- 统一错误、确认、保存成功和资源不足反馈。
- 对相关美术候选执行实际界面审稿。

### 玩法

- 只提供新手引导步骤、帮助术语和设置选项所需的只读数据契约。
- 不因 UI 需要复制规则；Deck/Battle/Progression/Challenge 规则保持现有基线。

### 数值

- 本版本不新增构筑内容。
- 验证设置、备份和引导不改变战斗与抽卡结果。
- 对 v0.7 三套牌组做一次回归采样。

### 本地数据层

- 设置存储、引导已读状态、备份恢复和设置损坏回退。
- 不改变现有 v5 游戏进度 schema；设置使用独立 `user://` 文档。
- 恢复备份前校验目标档，失败时保留原件。

### 美术

- 设置/帮助/存档图标、引导装饰和必要的状态插画。
- 不重绘已通过 v0.7 审稿的核心卡面。

### 产品经理与主协调者

- 冻结帮助步骤、设置字段、备份恢复语义。
- 阻止新增途径、章节或大批卡牌。
- 完成全量回归、独立构建和项目外启动验证。

## 5. 验收标准

- 首次启动可跳过或在 3 分钟内完成引导。
- 设置重启后保持；非法设置安全回退。
- 主档、备份、损坏档均显示正确状态。
- 恢复备份和新游戏覆盖均有确认，失败不破坏当前可读档。
- 战斗详情、升级预览和事件日志没有规则计算渗入 UI。
- v0.7 首次路线、第一挑战、第二挑战、牌组编辑、抽卡和升级回归全部通过。
- UI 对 v0.8 美术实际界面审稿。
- 独立构建运行无资源缺失错误，项目外启动退出码为 0。
- 无新增无调用方框架、绝对路径或重复事实源。

## 6. 明确非目标

- 第二条途径、更多序列、第二章节。
- 新增战斗卡、敌人或挑战修饰。
- 多人、联网、付费、云存档和账号。
- 音频、配音、商业美术替换、复杂动画。

## 7. 风险与质量门

| 风险 | 预防 | 处理 |
|---|---|---|
| 引导遮挡操作或强制阅读 | 可跳过、短步骤、可从帮助重开 | UI 前向修正 |
| 设置文档损坏阻断启动 | 独立设置文件与安全默认值 | 保留原件并提示 |
| 备份恢复覆盖当前档 | 校验、确认、临时文件 | 失败保留当前档 |
| 战斗说明重算规则 | 只读快照与内容描述 | UI/领域接口前向修正 |
| 收口版本偷偷扩内容 | PM 范围门 | 新点子进入候选池 |

## 8. 下一版本入口

v0.8.0 通过后才评估第二途径或第二章节。当前优先保证第一次游玩顺畅和独立构建稳定。
