# v0.9.3 Pending 导航韧性补丁

## 1. 版本信息

- 日期：2026-11-08
- 状态：已关闭
- 类型：质量补丁
- 主题：所有关键异步等待页面保持可返回或可取消
- 用户价值：避免命令挂起、迟到响应或界面锁定时把玩家困在页面中

## 2. 用户问题承接

用户此前多次报告抽卡和战斗无法退出。`v0.9.2` 修复了这两条直接路径；本版本继续按破坏性思路审查其他带有 pending 的页面，发现挑战、牌组、升级、路线和仪式仍会在等待时禁用返回/取消。

当前结算多为同步调用，因此问题不一定会稳定触发，但页面契约本身保留了未来卡死风险。本版本直接修正结构，不在故障发生后再叠条件分支。

## 3. 修复范围

| 页面 | 旧行为 | 新行为 |
|---|---|---|
| 挑战修饰/开始 | pending 时退出按钮禁用且请求被拒绝 | 退出始终可用 |
| 牌组编辑 | pending 时返回禁用且请求被拒绝 | 返回始终可用；修改类按钮仍受限 |
| 卡牌升级 | pending 时返回禁用 | 返回始终可用 |
| 路线地图 | pending 时返回白昼档案禁用 | 返回始终可用 |
| 晋升仪式 | pending 时取消禁用 | 进行中始终可取消 |

重要边界：

- 仍禁止重复提交结算命令。
- 返回只负责离开当前界面；已完成的领域结果仍由现有检查点机制决定。
- 不改变玩法规则、卡牌数值、存档 schema 或路线内容。

## 4. 破坏性回归

- 检查仪式取消发送稳定 `CANCEL_RITUAL` 命令。
