# v0.35.0 战斗桌面：拖放手感与物件化 HUD

- 日期：2026-11-11
- 状态：执行中
- 前一版本：`v0.34.0`（工程交付有条件关闭；悬停可发现性并入本版桌面手感验收）

## 1. 用户价值

打廷根应像在值夜者桌面上操牌：拖出去就打出，悬停能看清卡面，资源与意图是桌上物件，而不是点菜单 + 读 tooltip。

## 2. 必须交付

1. **拖放打出**：手牌拖向敌人/战场可打出；指向线提示目标；点选路径保留为降级。
2. **悬停大卡**：手牌悬停抬升放大；关键费用与效果仍可读。
3. **物件化资源**：生命 / 灵性 / 污染 / 被注视用分段条 + 图标呈现（数值仍来自快照）。
4. **意图姿态**：攻击 / 诅咒 / 防备图标；危险意图有清晰姿态高亮。
5. **联动提示**：部分满足的联动高亮对应手牌。
6. **舞台减负**：1600×900 主战场少嵌套滚动；小窗仍保留页滚动降级。
7. **回归**：v0.31 布局隔离、v0.34 档案控件、价值审计与关键 UI 烟测仍绿。

## 3. 明确非目标

- 不解冻小丑、不扩第二途径、不新卡、不改战斗公式。
- UI 不计算规则；拖放只提交既有 `BattleCommand`。
- 不重做牌组/祈愿页为炉石收藏式 UI。

## 4. 角色

| 角色 | 任务 |
|---|---|
| 产品经理 | 开版；有条件关闭 v0.34 |
| UI | 战斗桌面手感全套 |
| 玩法 | 仅当快照字段不足时最小改动（本版默认只读） |
| 主协调者 | 回归与版本号 |

## 5. 验收

- 可用拖放打出需目标 / 无需目标牌；点选仍可完成同一命令。
- 悬停放大不破坏 ADR-0030 固定区域。
- 意图图标与危险高亮可见。
- 关键自动化绿。
