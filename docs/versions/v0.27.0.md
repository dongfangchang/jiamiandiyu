# v0.27.0 攻击体系与战斗记录窗口

## 1. 版本信息

- 日期：2026-11-09
- 状态：执行中
- 类型：机制设计与战斗可读性版本
- 前一版本：`v0.26.0`

## 2. 用户价值

玩家可以在不挤压手牌的战斗记录窗口中追踪最近事件，并能从卡牌文本看懂攻击针对的是肉体、灵体还是灵魂。攻击设计遵循占卜家序列 9 到小丑序列 8 的能力梯度，先做预兆、信息差、标记、错位和精准动作，再逐步引入腐蚀、净化和低强度命运干涉。

## 3. 本版本范围

1. 战斗记录改为侧栏内独立的垂直滑动窗口，最多保留最近 10 条，新增记录自动滚到最新位置。
2. 新建攻击体系设定文档，定义六种伤害、五种攻击形态、五类特殊干涉、五类抗性和肉体/灵体/灵魂三层规则。
3. 为 40 张卡牌补充伤害类型、攻击形态、途径、序列梯度、目标层、机制标签、规则文本和氛围文本。
4. 新设计卡牌继续使用已有卡背回退图，不在本版本阻塞于批量正式美术。
5. 运行时保持现有已注册效果和快照契约；本版本不在 UI 侧伪造抗性、DOT 或特殊干涉结算。

## 4. 非目标

- 不新增第二途径、第二章节或高序列能力。
- 不直接把未注册的 `effect_id` 写进卡牌效果数组。
- 不修改存档 schema、公共命令结构和现有战斗数值公式。
- 不为每张新卡制作正式 PNG；未知卡图必须回退到卡背。

## 5. 验收标准

- 1600×900 和窄视口下，战斗记录不会改变手牌面板高度，八张手牌仍可见且可点击。
- 记录超过 10 条时只显示最近 10 条，并自动跟随最新记录。
- 40 张卡牌都具备完整攻击体系元数据和可直接印刷的规则/氛围文本。
- 卡牌加载、牌组、升级和战斗回归不因新增元数据失败。
- 所有无正式卡图的定义通过统一卡背回退路径显示。
- `V027_ATTACK_CATALOG_OK` 和 `V027_BATTLE_LOG_OK` 通过。
- 相关 UI、玩法、整合和格式检查通过。

## 6. 后续机制切片

v0.28.0 再选择一组低序列效果实现最小运行时闭环：`damage_type`、目标层、单一抗性、一个 DOT 状态和一个可审计的命运干涉事件。完成后再扩展召唤物、空间攻击和力量窃取，避免一次性引入无法验证的复杂规则。
