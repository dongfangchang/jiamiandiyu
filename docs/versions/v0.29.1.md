# v0.29.1 序列9占卜家深化

## 版本信息

- 日期：2026-11-09
- 状态：验证中
- 前一版本：`v0.29.0`，规划中的小丑切片暂缓

## 版本方向

本补丁暂缓序列8「小丑」实现，先把序列9「占卜家」的核心扮演做成可感知的战斗闭环：灵视揭示意图、预见降低下一次攻击、仪式准备叠层、预兆强化标记，并在战斗记录和状态栏中明确反馈。

## 实现范围

- `reveal_intent` 成功后获得一次性“预见”，下一次敌方攻击伤害降低1点。
- `守夜圆环`新增“仪式准备”，最多3层。
- 仪式准备达到3层后，下一次施加“标记”额外增加1层并消耗准备。
- UI显示“预见”和“仪式准备”状态、触发记录和浮动反馈。
- 扮演消化规则继续只接受占卜、预感、意图揭示、标记、灵性视觉、仪式和推演标签。

## 公共接口与数据约束

- 继续使用现有 `reveal_intent`、`apply_status`、战斗快照和事件机制；`prepare_ritual` 是本切片新增的已注册效果 ID。
- `foresight` 为一次性玩家状态；敌方下一次攻击结算后必须消费并记录 `ForesightConsumed`。
- `ritual_preparation` 最多 3 层；下一次对敌方施加 `mark` 时增加 1 层标记并记录 `RitualPrepared`，随后清除准备层。
- UI 仅读取状态和事件，不复制伤害、标记叠层、合法性或消耗逻辑。
- 不修改存档 schema、RNG 合同、稳定内容 ID、序列 8 规则或封印物内容。

## 明确不做

- 不实现小丑戏法、迷惑、精准投掷、闪避反击。
- 不新增第二途径、封印物或高级命运改写。
- 不制作新卡图，继续使用卡背回退。

## 验收标准

- 揭示敌方意图后，下一次攻击只减少1点且状态一次性消耗。
- 三次仪式准备后，下一次标记获得额外1层并消耗准备。
- 非法卡牌、空目标、重复命令不改变上述状态。
- 旧版玩法、进度、路线、后端和 UI 回归保持通过。
