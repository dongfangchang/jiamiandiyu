# v0.28.0 第一阶段：扮演消化、魔药战利品与章节地图

## 1. 版本方向

本版本把成长主线从“战斗后选择通用奖励”改为“按原著剧情推进调查，在战斗中完成扮演，章节结束获得魔药，满足消化度后服用并晋升”。章节节点不再被固定为十关；路线数据允许 3—12 个节点，由剧情需要决定战斗、休整、调查和首领的位置。

序列 9 占卜家的扮演围绕灵视、占卜、预兆、意图揭示、标记和仪式准备。序列 8 小丑的扮演将在后续章节加入戏法、迷惑、身体控制、精准投掷和闪避反击。卡牌使用是扮演行为的可验证来源，只有规则层确认打出卡牌后才增加消化度。

## 2. 本版本已实现范围

- 进度状态新增扮演消化度、魔药库存和序列推进字段。
- 使用带有占卜家扮演标签的卡牌后增加消化度；重复点击、非法牌和被拒绝命令不增加。
- 章节完成后只授予路线声明的魔药战利品，不从抽卡、商店或其他路径获得。
- 路线结算页显示魔药和消化度；只有消化度达到要求才启用服用按钮。
- 服用命令由玩法层校验，成功后推进到序列 8「小丑」，并持久化。
- 路线地图使用独立横向滚动容器；节点数量由内容决定。
- 遭遇支持连续波次数据，当前波次全部解决后才生成下一波并记录 `EnemyWaveArrived`。

## 3. 原著能力边界

序列 9 不直接拥有高强度灵魂攻击、完整命运改写、空间传送或秘偶控制。序列 9 的牌用信息、准备和媒介制造优势。序列 8 的戏法表现为误导、身体控制、假动作、精准投掷和闪避后的反击，不能写成高序列魔术师能力。

## 4. 后续章节入口

第一阶段完成后，新增序列 8 章节：先用小丑魔药解锁戏法标签，再让敌人拥有伪装意图、错位、诱导和反击窗口。封印物作为章节战利品或剧情事件出现，每件封印物必须同时定义能力、负面效果和使用条件。魔药仍只从对应章节战利品获得。

## 5. 验收标准

- 消化度只由已结算的扮演卡牌增加。
- 魔药未掉落、消化度不足、序列不匹配时均不能服用。
- 服用后重启仍保留序列 8 状态，重复服用被拒绝。
- 路线地图在小视口可以横向滑动到所有节点。
- 连续波次按顺序出现，不能在第一波结束时提前结束战斗。
