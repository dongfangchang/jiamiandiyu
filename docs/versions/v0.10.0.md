# v0.10.0 战斗连携与灵性回响

## 1. 版本信息

- 日期：2026-11-08
- 状态：已关闭
- 类型：玩法功能版本
- 主题：同回合连携与非阻断界面反馈
- 用户价值：让战斗从单纯逐张出牌变成可规划的小型连携循环

## 2. 范围

### 必须实现

- 同回合成功打出 `cost_spirit > 0` 的卡牌会累积连携。
- 连携阈值、伤害、抽牌和灵性恢复全部来自 `data/balance/v0.7.0/balance.json`。
- 达到阈值时触发一次“灵性回响”：对全部存活敌人造成伤害、抽牌并恢复灵性。
- 触发后和回合结束时连携清零。
- 战斗快照提供只读 `chain` 字段；BattleEvent 提供 `ChainChanged`、`ChainTriggered`。
- UI 显示当前连携与阈值，并在触发时显示浮字、脉动和中文日志。
- 缺少 `chain` 的旧快照安全隐藏连携徽章。

### 明确不做

- 第二途径、第二章节、新卡池、新敌人。
- 多人、联网、服务器或异步后端。
- 新存档字段；连携只存在于战斗运行时。
- 商业美术替换。

## 3. 规则

```text
非零灵性牌成功打出 → chain + 1
零费牌 / 被拒绝命令 / 卡牌效果内部动作 → 不增加
chain == threshold → 触发一次回响 → chain = 0
结束回合 → chain = 0
```

回响默认配置：

```json
{
  "threshold": 3,
  "damage": 1,
  "draw": 1,
  "spirit": 1
}
```

灵性恢复上限为玩家最大灵性。回响伤害使用稳定来源 ID `chain.echo`。

## 4. 架构与接口

- `BattleEngine` 读取 `battle.chain` 平衡参数。
- `BattleSnapshot.chain` 为只读展示状态。
- `ChainChanged` 记录累计和清零。
- `ChainTriggered` 记录本次回响配置。
- UI 不计算阈值、伤害、抽牌或灵性。
- 不修改 Save schema；重开战斗时连携自然从 0 开始。
