# v0.32.0 廷根可玩验收：真人试玩、难度收口与发布证据

- 日期：2026-11-10
- 状态：有条件关闭（难度收口与远程推送完成；真人试玩表与完整窗口门转入 `v0.33.0` 候选）
- 前一版本：`v0.31.0`（有条件关闭：本地功能完成；本轮允许随基线推送远程）
- 关闭说明：2026-11-10 产品经理有条件关闭。

## 1. 用户价值

玩家在完成 v0.31 原著重构后，应能稳定走完廷根第一阶段：看得懂仪式/首领/联动，打得有压力但不无解，关键页面在 1600×900 与 1100×700 下操作可达且中文可读。本版本不扩内容面，只把“能玩且可验收”收成关闭条件。

## 2. 必须交付

1. **真人试玩记录**：至少覆盖密修会 → 提利尔 → 伍德家恶灵 → 拉姆德/老尼尔 中的 3 个战斗节点，以及一次仪式页与一次联动触发；写成结构化试玩报告。
2. **难度收口**：在保留价值审计模型的前提下，下调贪心抽样中明显过松的首领/精英（目标：关键首领贪心胜率不再普遍 95%–100%，或若真人反馈已足够难则记录“不调参”的证据）。数值只改 `data/balance/**` 与敌人/遭遇数据中的战斗参数，不重写卡牌身份。
3. **回归确认**：在 v0.31 内容之上复测 BUG-0022/0023/0024（序列锁定文案、抽卡重进不残留、中文缺字）与旧档/挑战兼容入口。
4. **窗口证据**：补齐主路径截图（路线、战斗含首领阶段、牌组锁定态、抽卡空态重进、仪式）于 `.tools/ui-captures/v0.32.0/`，含 1600×900 与至少一组 1100×700。
5. **自动化门**：日常最小集 + 版本门全量 QA；至少保留 `V031_CARD_VALUE_AUDIT`、`V031_CANON_BATTLE` 与本版本新增难度/验收 runner。

## 3. 明确非目标

- 不推送远程（除非用户另行明确要求）。
- 不解冻序列 8「小丑」技能包，不开放魔术师及以上。
- 不开放第二途径、贝克兰德/海上可玩内容。
- 不新增卡牌稳定 ID，不重做 40 张卡的价值模型。
- 不进行正式卡图/敌人立绘大包（可进候选池；现有回退立绘可接受）。
- 不把 NovelToGame / Game-Studios 模板目录引入本仓库。

## 4. 角色任务与依赖

| 顺序 | 角色 | 任务 | 可编辑范围 |
|---|---|---|---|
| 1 | 产品经理 | 开版、范围冻结、试玩条目裁决、关闭条件 | `docs/**`、`AGENTS.md` |
| 2 | 主协调者 / QA | 跑基线 QA、组织试玩证据、集成回归 | `tests/integration/**`、截图目录、协调者报告 |
| 3 | 数值设计 | 根据抽样与试玩调整首领/精英压力；保持价值审计通过 | `data/balance/**`、`data/enemies/**` 中战斗数值字段（若需改敌人数值须在报告请求并由产品经理确认单一写入）、`tools/simulation/**`、`tests/simulation/**` |
| 4 | UI | 补窗口证据；仅修验收中发现的 S1/S2 可达性或文案映射问题 | `src/ui/**`、`scenes/ui/**`、`assets/ui/**`、`tests/ui/**` |
| 5 | 玩法 | 仅当试玩暴露规则语义错误时前向修复 | `src/gameplay/**`、`tests/gameplay/**`、相关 `data/**` |

依赖顺序：产品经理开版 → 协调者基线 QA → 试玩记录 → 数值调参（若需要）→ UI/玩法按缺陷面最小修复 → 版本门全量 QA。

敌人数值若需修改：产品经理在本版本授权数值设计为 `data/enemies/v0.7.0/enemies.json` 的临时单一写入者；玩法不同时改该文件。

## 5. 公共接口与数据

- 不改存档 `save_version` 语义；不改稳定内容 ID。
- 难度调参优先改 `data/balance/**` 的压力线/阶段参数；不足时再调敌人 hp/attack/阶段阈值。
- 卡牌效果与价值单位表保持 v0.31 定义；联动奖励上限公式不变。

## 6. 验收标准

- 试玩报告存在且条目勾选，不把“设计意图”写成已验证。
- 若调参：抽样报告给出调前/调后胜率与回合数；价值审计仍通过。
- 若不调参：必须有真人试玩说明“压力足够”的记录。
- BUG-0022/0023/0024 回归命令与结果写入报告。
- `.tools/ui-captures/v0.32.0/` 含约定页面；1100×700 操作入口不被裁切。
- 全量 QA 退出码 0；缺少窗口证据不得关闭版本。

## 7. 风险与回滚点

- 风险：下调首领后前半普通战仍过松，或上调后卡关。缓解：只动首领/精英层，普通遭遇先不动。
- 风险：未提交的 v0.31 大改与本版本改动混杂。缓解：本版本报告明确区分“继承 v0.31 未推送基线”与“本版本新增提交面”；仍不推远程。
- 回滚：仅在无法启动、存档破坏或结构无法前向修复时评估；默认前向修复。

- 序列 8 小丑可玩深化。
- 独立 Windows 构建重导出（若试玩未阻断可延后）。
- 远程推送与版本发布说明。
