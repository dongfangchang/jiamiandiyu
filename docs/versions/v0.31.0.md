# v0.31.0 廷根原著重构：卡牌平衡、玩法可读与界面互不挤压

- 日期：2026-11-10
- 状态：有条件关闭（本地功能与专项 QA 完成；完整发布门、远程推送与真人难度复测转入 `v0.32.0`）
- 前一版本：`v0.30.1`
- 关闭说明：2026-11-10 产品经理有条件关闭；未推送远程的约束仍然有效。

## 1. 用户反馈与版本目标

1. 卡牌技能完全不数值平衡，作用与代价对不上。
2. 界面中任一画框变化会挤压其他画框。
3. 仪式、首领状态、卡牌联动等玩法对玩家不明显。
4. 内容须符合《诡秘之主》原著：参考主角遇到的战争/经历与所用封印物、技能。

## 2. 已实现

### 2.1 卡牌与数值（40 张，稳定 ID 不变）
- 每张卡重写为原著对应物：左轮手枪、猎魔子弹、灵性之墙、圣夜粉、驱邪仪式、银质匕首、灵视、黄水晶灵摆、梦境占卜、塔罗占卜、魔镜占卜、危险预感、通灵、冥想、查尼斯门值守、灰雾之上、塔罗会、值夜者支援（伦纳德/邓恩/圣赛琳娜骨灰），以及封印物 2-049、2-105、3-0625、3-0611、3-0782、阳炎符咒、安提哥努斯家族笔记、阿兹克铜哨；序列 8 小丑：飞牌、纸牌连掷、危险预感、身体控制、预判下一步、闪身反击、小丑的微笑。
- 统一价值模型定价并由 `tests/simulation/v031_card_value_audit_runner.gd` 自动审计（0 费 2.5 / 1 费 5.5 / 2 费 10.5 / 3 费 15.5；稀有 +1、序列8 +1、单场一次 ×1.3；污染 -2、被注视 -1）。所有封印物必须有负面效果或单场一次。
- 详见 `docs/design/TINGEN_CANON.md`。

### 2.2 新机制（`BattleEngine`）
- 仪式准备 3 格 + 消耗式终结技（每层 +3）、束缚、闪避、失声、窃取攻击、迟缓、单场一次（exhaust）。
- 敌人特质（灵体/不死/污秽/失控者/非凡者/人类）、意图循环（攻击/诅咒/防备）、危险预感标记（伤害≥9 或污染≥2）。
- 血量阶段（`at_hp_percent`）与回合阶段并存；阶段可改意图、加威胁、施加污染/注视。
- 被注视追猎线（≥7 攻击 +1、满值 +2）、污染惩罚线（≥7 每回合 -1 生命）。
- 数据驱动原著联动 `synergies`（同一回合组合触发），共 9 条。

### 2.3 内容重写
- 敌人：密修会成员、绑匪、失控的瑞尔·比伯、燕尾服小丑（精英）、附身恶灵、骑士怨魂、失控的代罚者、失控的老尼尔（首领）、梅高欧丝（首领，三阶段）。
- 章节约 8 节点：6/30 密修会 → 7/6 艾略特绑架案 → 7/12 提利尔仓库 → 7/15 伍德家的恶灵 → 占卜俱乐部休整 → 8/19 拉姆德小镇驱邪 → 8/29 失控的老尼尔 → 8/31 晋升小丑。
- 挑战改为「值夜者档案：笔记案」「值夜者档案：邪神子嗣降临」。
- 仪式改为原著「占卜家/小丑扮演守则 + 晋升流程」与「转运仪式」；仪式页显示原著出处与三步进度。
- 四套预设：值夜者制式装备 / 仪式魔法 / 提利尔仓库 / 值夜者小队。

### 2.4 界面互不挤压（ADR-0030）
- 主题新增 `clip_label` / `fixed_text` / `fixed_scroll`：动态文本单行省略并保留 tooltip，长篇详情进入固定高度滚动框。
- 战斗页重排为固定区域：页头、状态条（仪式槽 + 风险线）、中段（战场情报 + 敌列 + 行动/联动/日志）、手牌；滚动提示常驻预留行。
- 路线、牌组、仪式、结算、抽卡、休整、身份页的页脚状态、章节摘要、当前目标、节点剧情、卡牌预设摘要、详情文本全部改为固定高度，不再随内容撑开。
- `tests/ui/v031_canon_battle_runner.gd` 在 1600×900 与 1100×700 下比对十个区域矩形，阶段/联动/日志增长后坐标不变。

### 2.5 玩法可读性
- 战场情报条：首领名称、阶段 n/m、当前阶段描述、下一阶段触发条件与应对提示。
- 敌列：特质、威胁、阶段徽标、危险预感警告、可横向滚动的状态行。
- 联动面板：列出牌组内的原著联动、完成进度、触发状态，tooltip 含效果与原著出处。
- 手牌：单场一次/兑现仪式/联动标签，效果文本可滚动，tooltip 含出处。
- 触发联动、阶段切换、仪式完成时在特效层弹出横幅（不参与布局）。
