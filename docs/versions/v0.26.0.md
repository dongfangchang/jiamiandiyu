# v0.26.0 机制版本：构筑联动与战斗反馈

## 1. 版本信息

- 日期：2026-11-09
- 状态：验证中
- 类型：机制版本
- 前一版本：`v0.25.0`

## 2. 用户价值

玩家能看懂卡牌为什么值得升级、当前是否拥有某张卡、敌人何时强化以及每次攻击造成了什么结果。战斗构筑从单卡功能升级为标记、削弱、抽牌、灵性与连携之间的组合选择，并且玩家能随时回到主菜单或重新开始。

## 3. 本版本范围

1. 卡牌升级页突出“现在可以升级”、升级前后效果和立即升级入口。
2. 成长档案增加回到主菜单、重新开始入口；战斗退出继续保留安全返回路径。
3. 牌组卡牌使用统一的“已拥有 · 可加入 / 未拥有 · 仅可查看”状态样式，避免拥有状态与操作按钮割裂。
4. 卡池扩展至 40 张唯一卡牌，新增 20 张卡牌；新增卡牌全部进入内容目录、祈愿池或收藏、升级与牌组链路，并通过组合效果形成联动。
5. 战斗反馈强化：受到伤害显示大号数值、红色闪击和短促震动；攻击敌人显示明确伤害文本和命中反馈；敌方压力与阶段强化显示在敌人列和战斗记录中。
6. 手牌卡牌固定为统一尺寸，不因手牌数量变化而拉伸。

## 4. 非目标

- 不新增章节、途径或付费系统。
- 不修改存档 schema、稳定内容 ID、RNG 合同和公共命令结构。
- UI 不复制伤害、概率、合法性或胜负计算；所有数值继续来自规则层快照和事件。

## 5. 机制设计

新增卡牌围绕四类可组合关系：

- 标记 → 伤害：先施加标记，再用伤害牌触发额外伤害。
- 削弱 → 生存：在敌方攻击前施加削弱，配合护盾和治疗拉长窗口。
- 抽牌 / 灵性 → 连携：用抽牌与灵性牌凑齐回响阈值，再利用群体回响收尾。
- 代价 → 回报：污染或被注视上升换取更高伤害、更多抽牌或更强防守。

敌人继续使用已有的压力和阶段数据驱动强化机制；本版本补齐其可视化反馈，不在 UI 侧重算强化。

## 6. 验收标准

- 牌组编辑器显示 40 张卡牌目录，未拥有卡牌仍可查看但不能误认为可加入。
- 新增卡牌可以被内容加载、祈愿、升级和牌组快照识别。
- 升级条件满足时，卡牌行有明确高亮和“立即升级”按钮；条件不足时给出差额。
- 成长档案可回到主菜单并重新开始路线。
- 1600×900 与 1100×700 下战斗手牌卡牌尺寸固定，主要操作可达。
- 伤害、受击、敌方压力和敌人阶段强化在战斗记录与画面反馈中可见。
- 玩法、成长、UI、整合、格式检查和内容加载回归全部通过。
