# v0.9.4 界面真实性与可读性补丁

## 1. 版本信息

- 日期：2026-11-08
- 状态：已关闭
- 类型：非阻断体验补丁
- 主题：修正路线页对比度、成功结算原因和奖励页误导文案
- 用户价值：界面不再显示与真实状态矛盾的信息，路线关键信息可直接阅读

## 2. 问题分级

本轮三个问题均为 S3/非阻断，不冻结下一功能版本：

- 路线页顶部在浅色背景上对比度偏低。
- 路线成功但快照缺少 `end_reason` 时，标题写“晋升完成”，原因却写“规则层未提供原因”。
- 奖励页文案写“或返回白昼档案”，但存在必选奖励时返回按钮实际禁用。

## 3. 修复

- 路线页标题区使用独立深色面板，摘要、资源和挑战信息保持高对比度。
- 成功路线缺少结束原因时推断为 `ascension_completed`，显示“三步晋升仪式完成”。
- 奖励页在必须选择奖励时隐藏不可用的返回按钮，并把提示改为“必须选择一份战利品”。
