## 用户反馈与范围

1. 序列 9 档案中的提灯步显示“已拥有 · 可加入”，点击后却返回 `sequence_locked`。保留能力限制，由玩法快照统一说明能否加入及限制原因，UI 显示中文提示。
2. 抽卡后返回再进入仍显示上次结果。将本次页面的展示状态与持久化成长结果分开，重新进入为空；收藏、券、保底和残页不得被清空或重复结算。
3. 旧关卡没有完成新体系更新，从新游戏选择入口下架。仅开放「廷根异常调查·第一阶段」，以未开放的后续规划占位；旧路线稳定 ID 和必要数据保留，供旧存档和既有挑战兼容。
4. 截图部分汉字显示方框。核对文本编码、字体字符覆盖及回退策略，修复实际缺字原因；不以替换正常汉字或隐藏文本掩盖问题。

### 字体依赖评审

font_deck_fix 已复现系统字体未匹配中文、显式请求 PingFang SC 仍落到 PingFang HK，且“敌”“稳”的字符覆盖检查失败。产品经理与主协调者兼应用/数据层负责人共同批准携带 `NotoSansCJKsc-Regular.otf` 完整简体字库：来源为 `notofonts/noto-cjk` 的 `Sans/OTF/SimplifiedChinese`，采用 SIL Open Font License，约 16 MB；它是静态资源，无执行依赖。提交前由主协调者复核固定上游版本、SHA256、许可证与资产记录，确认覆盖测试通过。完整字库避免按当前文案裁字后新增内容再次缺字，成本是仓库和导出体积增加。

## 原著进度边界与后续计划

- 当前第一阶段仍含原创镜厅、男爵、讣告原型。章节标题和文案不代表原著剧情已实现，v0.30.0 也未完成用户要求的路线与战斗流程重写。
- 后续规划按廷根后续调查、小丑阶段 → 贝克兰德的魔术师/无面人阶段 → 海上无面人阶段排列。这是阶段占位，不承诺本补丁开放内容，不让玩家直接跳至高序列。
- 当前实现继续聚焦序列 9 占卜家。小丑技能冻结；不因 UI 显示错误放宽序列门，不加入秘偶、空间转移或高级命运改写。
- 本补丁完成后优先审定占卜家阶段的原著事件、可参与的战斗与队友支援边界，再替换原创节点和遭遇。魔药仍仅作为章节战利品，消化度与服用晋升规则保持。

## 验收标准

- 已拥有但序列不足的提灯步显示锁定及所需序列，加入按钮不可用；直接命令仍安全拒绝。合法卡牌和移出操作不被误锁，原因不泄漏原始英文码。
- 单抽/三连返回真实结果，详情可读；返回后重进（包括恢复存档后进入）不显示旧结果，下一次抽卡能正常显示新结果，券、收藏、保底不会重置。
- 新游戏只有第一阶段可开始；规划节点清楚标注未开放，点击和程序请求都不能开始。旧检查点及底层挑战引用仍可解析。
- 源文本无损坏字符；截图出现方框的汉字验证覆盖，目标平台窗口中的正常中文可读。
- 最小专项、相关破坏性与应用回归通过；记录命令、结果、实际窗口证据和未决风险。未取得证据不填写通过数字，不把代码推送等同于发布验收。
