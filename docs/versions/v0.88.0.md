## 3. 黄金回放策略

- R2 会给快照**增加字段**，并把文案**改为 ID**，所以哈希必然变化。
- **各轨道不得自行执行 `--update`**。各轨道在报告中附上规范化快照的前后语义差异，证明只有"新增字段"或"文案改 ID"，没有任何数值或状态变化。
- 每一波合并后，由主协调者统一更新一次 `expected.json`，并在本文件登记。
