## 1. 版本信息

- 日期：2026-11-08

## 2. 独立 QA 发现

- 第三张付费牌直接击杀最后敌人时，旧实现仍发出 `ChainTriggered`，但之后跳过回响抽牌和回灵，事件与真实结算不一致。
- 回响伤害击杀全部敌人时也提前返回，导致声明效果未完整结算。
- `balance.schema.json` 未校验 `combat.chain`，错误配置可能静默禁用连携。
- 原测试未覆盖拒绝命令、直接击杀、抽牌重洗和手牌上限。

## 3. 修复

- 卡牌效果结算后先检查战斗是否结束；已结束时不再推进空连携。
- 回响伤害、回灵和抽牌全部完成后再进行最终胜负检查。
- schema 强制要求 `combat.chain`，阈值至少为 1，其他效果参数为非负整数。
- 补充正式平衡表、拒绝命令、直接击杀、弃牌堆重洗和手牌上限测试。
