# v0.21.0 预设费用指标可视化

## 1. 版本信息

- 日期：2026-11-08
- 状态：已关闭
- 类型：构筑可读性
- 主题：在预设选择卡片中显示可解释的费用负担
- 前一版本：`v0.20.0`，已关闭；预设指标基线已建立

## 2. 范围

- 从已有牌组快照中的卡牌费用读取每套预设的平均费用和最高费用。
- 在四套预设卡片中显示“8 张 · 平均费用 · 最高费用”摘要。
- 缺失卡牌数据时显示可读回退，不阻塞载入和自定义牌组。

非目标：不改牌组内容、战斗规则、数值数据、存档或公共契约。

## 3. 验收

1. 四套预设在数据完整时显示费用摘要。
2. 空数据或缺失卡牌时页面仍可操作。
3. 牌组 UI、通用 UI、平衡指标、headless 和格式检查通过。

## 4. 关闭结论

- 四套预设卡片显示费用均值、最高费用和卡牌数量。
- 完整数据、缺失数据的回退路径均可用。
- `V07_DECK_UI_SMOKE_OK checks=50` 和 `V020_PRESET_METRICS_OK checks=72 presets=4` 通过。
