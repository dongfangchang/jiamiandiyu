# v0.14.0 自适应战斗布局与第四预设

## 1. 版本信息

- 日期：2026-11-08
- 状态：已关闭
- 类型：UI 可靠性 + 构筑功能
- 主题：彻底处理卡牌裁切，并新增“镜中余响”预设
- 用户价值：较小窗口和放大 UI 下仍能访问完整手牌；20 张卡形成第四套官方构筑方向

## 2. 卡牌裁切修复

### 根因

- 战斗页假设固定 1600×900，没有窄视口降级路径。
- 手牌区使用固定最小高度。
- 非全屏窗口未限制在桌面可用区。
- UI 放大后有效布局空间进一步减少。

### 修复

- 战斗页面增加横向/纵向页面滚动兜底。
- 1600×900 基准布局不显示页面滚动条。
- 1366×768、1333×750、1280×720 可滚动访问战场、手牌和按钮。
- 聚焦控件时自动滚动。
- 非全屏窗口启动时 clamp 到操作系统可用桌面区域。
- 整卡点击和底部选择按钮均保留。

## 3. 第四预设

新增 `deck.preset.echo`「镜中余响」：

```text
梦问 · 镜面替身 · 断线 · 临终圣礼
```

预设使用四张新卡建立标记、控制、防御和续航组合。四套预设可在 1600×900 同屏浏览。
