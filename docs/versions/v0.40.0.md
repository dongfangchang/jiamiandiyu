## 1. 用户价值

服用小丑魔药后，玩家**立刻**能用上序列 8 的八张既有卡：收藏解锁、牌组有「小丑」预设、原著联动「小丑」可打出。设计先封死稳定 ID 与构筑语义，再进入正式立绘，避免卡面/规则/UI 各写一套。

## 2. 必须交付

1. **产品解冻**：撤销「不解冻小丑」冻结；仍不开放魔术师及以上与第二途径。
2. **方案 A**：不新增卡牌稳定 ID；启用既有 8 张 `序列8·小丑` 卡。
3. **晋升发放**：`digestion_rules.grant_definition_ids` 在服用魔药时写入收藏（`copies=1`，已有则不降级）。
4. **预设**：`deck.preset.clown`（八张小丑卡），晋升后自动选中并可确认出战。
5. **可读性**：牌组 UI 显示预设名/适合/慎用；结算页写明「已收容小丑技能包」。
6. **立绘门闩**：本版**不画**正式立绘；冻结 `docs/design/ART_BRIEF_V041.md` 作为 v0.41 唯一卡面清单。
