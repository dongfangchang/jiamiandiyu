## 1. 用户价值

玩家在牌组页就能看懂四套预设“适合打什么 / 什么时候别硬上”，尤其是值夜者小队对梅高欧丝的联动预期；同时把抽卡重进与序列锁定等关键修复锁进可重复自动化，避免原著重构后再回归。

## 2. 必须交付

1. **预设对抗提示**：`data/decks` 为每套预设提供 `strategy_tag_zh`、`best_against_zh`、`caution_zh`、`combo_focus_zh`；玩法快照透出；UI 只读显示。
2. **单一事实源**：UI 目录中的硬编码预设引导降为回退；有快照字段时优先快照。
3. **自动化**：
   - 牌组引导合同 / UI 冒烟覆盖四套预设的适合/慎用文案；
   - 抽卡重进不残留（复用并强化现有回归断言）；
   - 序列锁定中文原因仍显示且按钮不可加入。
4. **文档**：更新 `CURRENT_VERSION` / 角色报告；工程版本号 `0.33.0`。
