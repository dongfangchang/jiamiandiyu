# ADR-0004：敌方压力规则的生效时点

## 状态

已接受，替代 ADR-0003 中敌方压力的具体时点，其余内容保持不变。

## 背景

ADR-0003 规定战斗第 7 回合后、敌方行动完成时增加攻击。数值模拟显示谨慎构筑平均每场战斗只有约 4 回合，压力平均触发不到 1 次，且最高实际攻击加成为 0，无法处理拖延护甲流。

问题属于规则时点错误，不能通过继续降低玩家生命或增加兼容分支掩盖。

## 决策

首版敌方压力规则调整为：

1. 从每场遭遇的第 5 回合开始生效。
2. 第 5、7、9 回合开始时，所有存活敌人的基础攻击各增加 1。
3. 加成在生成本回合敌人意图之前应用，因此 UI 当回合就应显示已加成的最终伤害。
4. 同一场战斗内叠加；战斗结束后清零，不跨遭遇继承。
5. 战斗快照暴露 `enemy_pressure_bonus`，UI 只读取该值，不自行计算。
6. 没有存活敌人时不增加无意义的状态。

## 理由

- 规则简单，不引入额外资源或全局系统。
- 让慢速构筑在战斗进入后半段时承担真实风险。
- 与当前单场目标回合数一致，能在首版中实际被观察到。
- 当回合意图直接反映压力，避免玩家看到攻击后再被追加伤害的认知不一致。

## 后果

- 玩法 `BattleEngine` 需要修改压力触发时点和快照字段。
- UI 需要从第 5 回合起显示压力值。
- 数值模拟需要重新采样。
- 旧 ADR-0003 的压力时点不再作为实现依据；历史记录保留。

## 验证要求

- 第 4 回合没有压力。
- 第 5、7、9 回合开始前分别增加 1。
- 当前回合敌人意图包含压力加成。
- 战斗结束重置。
- UI 只显示快照提供的压力值。
