# ADR-0030：界面布局互不挤压红线

状态：已采纳
日期：2026-11-10

任何界面中，一个信息框、状态区、日志区或动态内容区的增长都不得改变其他可操作区域的可见尺寸。手牌、目标按钮、确认按钮、返回按钮和主要操作入口必须保持可见，或由它们自己的滚动容器承载。

实现要求：

- 动态文本和怪物状态必须放入有明确尺寸边界的区域；
- 互不相关的区域不得共享会被内容撑大的自适应高度；
- 新增状态、日志或详情前必须做 1600×900 与 1100×700 实际窗口检查；
- 回归必须验证操作按钮仍在视口内、手牌数量未因布局变化而减少，并验证滚动能够访问被裁切内容；
- 发现裁切或挤压时，先修复布局边界，再继续增加信息密度。
