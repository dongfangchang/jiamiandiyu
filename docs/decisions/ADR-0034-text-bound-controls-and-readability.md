# ADR-0034：控件绑定文字；替换即删除；日记可读性底线

状态：已采纳（用户 2026-11-24 反馈）
日期：2026-11-24
修订：ADR-0032 / `EXPERIENCE_ARCHITECTURE.md` §2.2、§3、§4、§5

## 背景

用户在 v0.88 之后反馈了三个问题：

1. **H-03 修错了方向。** 点书时露出旧界面，修法是"用黑幕遮住旧面板"，旧面板和它的按钮其实都还在（隐藏在桌面图下仍可点击）。旧界面应该**直接删除**，而不是遮挡。
2. **打开日记后字看不清，画风也太简陋。** 实测原因如下：
   - 页面 SubViewport 只有 512×720，正文 24px、注脚 16px，贴到斜放的 3D 页上再放大到 2920×1753 的视网膜窗口，字就糊了。
   - 镜头俯角 −59°，页面被压扁。
   - 桌和墙都是程序生成的方盒，铺平面纹理；`gl_compatibility` 渲染器没有 SSAO、也没有柔和阴影。
   - 右页只有三行字，大片空白。
3. **主界面的控件不该绑在画面物件上，应该绑在文字上。** 现在标题页的"继续 / 新游戏 / 挑战"是道具图上的隐形热区，玩家要猜哪个物件能点。

## 决策

### D1 控件 = 文字（修订 EXPERIENCE §2.2 / §3）

- 每个站位的可操作项都是**明确可读的文字条目**，位置固定，例如：书签纸条上的手写菜单、页边索引、桌沿书签。
- 物件**只是画面**，不承担入口职责。悬停或聚焦某个文字条目时，对应物件可以联动提亮或轻推镜头，作为视觉回应；但**点物件本身不触发功能**，也不作为唯一入口。
- `station.desk` 的"悬停物件 → 题签"改为：桌面一角固定一张**索引卡**，上面列出「日记 / 档案 / 卡匣 / 祈愿 / 卷宗 / 熄烛」；条目悬停时，对应物件提亮。
- 标题站：存档摘要和菜单（继续 / 新的日记 / 挑战 / 设置 / 离开）都写在书签纸条上，作为文字按钮。
- 日记站的蜡封仍是进关控件，但必须带文字（如「启」「再启」「已封」），并保持在右页固定位置。

### D2 替换即删除（新增规则）

- 新界面或新载体取代旧的时，**同一提交**里删除旧节点、旧代码和只为它存在的测试。
- **禁止**用以下方式"处理"旧界面：遮挡、`visible = false`、透明度归零、移出屏幕、挪到底层、隐形热区。
- 守卫：
  - 主路径代码中不得出现 `TitleOpenCover` 这类遮罩。
  - 标题站的场景树中，除文字菜单外不得有其他 `BaseButton`。

### D3 日记可读性底线（新增 EXPERIENCE §5.1）

- **3D 世界按物理像素渲染。** DeskWorld 视口尺寸 = 窗口物理像素（考虑 `content_scale` 和 HiDPI），不得先按 1600×900 渲染再放大。
- **页面 SubViewport 至少 1024×1440**（现在的两倍）；页面材质开启 mipmap 和各向异性过滤（以在兼容渲染器上实测为准）。
- **屏上字号底线**（按物理像素计，在 1600×900 逻辑窗口下等效）：
  - 正文 ≥ 20 px
  - 题名 ≥ 28 px
  - 注脚和符文说明 ≥ 15 px
- **对比度**：正文墨色对纸色 ≥ 4.5:1；注脚 ≥ 3:1。
- **阅读姿态**：书页平面与视线的夹角 ≤ 25°。可以调整默认镜头，也可以在悬停或按住时推近。
- **验收**：在 1600×900 和 2920×1753 两种窗口下各截一张；正文在原尺寸下肉眼可读。自动化测试断言视口尺寸跟随物理像素。

### D4 画面质量（新增）

- 由架构师评估渲染器：`gl_compatibility` 对比 Forward+ / Mobile，用同一镜头截图比较画面和帧率，结论写成 ADR。macOS M4 平台优先。
- 背景、桌面、书和道具的材质由美术按 `ART_BRIEF_DESK_WORLD.md` 的新增 §5（日记站画面升级）出图；UI 负责光照、后期和右页版式。

## 后果

- v0.88 的 H-03 方案作废，由 v0.89 的 X1-03 用"删除旧面板 + 文字菜单"取代。
- `DESK_WORLD_STATIONS.md` §3.3 的悬停题签交互改为索引卡（UI 修订）。
- DW-07 悬停题签资产改作索引卡条目底纹（美术可复用或微调）。
