# ADR-0032：书桌世界体验框架

状态：已采纳（用户授权架构师订框架，2026-11-24）
日期：2026-11-24

## 背景

用户在 v0.87 后反馈了四个问题：
1. 点书进入时会闪出旧界面。
2. 关卡切换卡顿、闪烁。
3. "继续"直接进入日记，管理牌组和抽卡还要再换屏。
4. 身份档案和当前风格严重割裂。

根因是项目没有定义"整个游戏是什么空间"，每个版本只替换当时在做的那一屏，结果三套视觉语言并存，并且彼此硬切。

## 决策

1. 采纳 `docs/architecture/EXPERIENCE_ARCHITECTURE.md`：整个游戏发生在同一张常驻书桌（DeskWorld）上。
   - 界面 = 站位（镜头 + 物件上的 2D 内容）。
   - 只有战斗和仪式离桌，并且经过墨迹门槛。
2. 过渡只允许四种：镜头移动、翻页、墨迹门槛、烛灭。
3. "继续"先落在桌面总览，再自动推近推荐站位；任何站位的上一级都是桌面总览。
4. 奖励、休息、结算并入日记页；选路线并入"卷"；牌组和升级合并为卡匣站。
5. 所有叙事文字使用思源宋体；面板一律使用纸、木材质；颜色只来自 `theme_tokens`。
6. 后续章节只能通过数据和美术增加（卷 / 章 / 开），不新增界面。
7. 实现分为 X1（v0.89）、X2（v0.90）、X3（v0.91），插在 ROADMAP 的 R2 和 R3 之间。R3 的界面拆分改为按站位拆分。

## 后果

- `identity_screen`、`route_select_screen`、`reward_screen`、`rest_screen`、`route_result_screen`、`upgrade_screen` 会在 X1–X2 中被站位取代并删除。
- `diary_desk_stage` 自带的 3D 世界并入常驻 DeskWorld。
- 美术需要新增档案夹、卡匣、祈愿台、抽屉、书签纸条、墨迹遮罩等资产（见 art 任务）。
- 新增的守卫：禁止 `add_background(`；禁止 `Color("#` 字面量；过渡期间禁止同步加载。

## 回滚

框架性决策不回滚。单个 X 条目如果出现回归，按 AGENTS §8 前向修复。
