## 版本规则

- 每个版本新建一个文件，不覆盖历史。
- 版本状态：`规划中`、`执行中`、`验证中`、`已关闭`、`已回滚`。
- 只有产品经理可以修改状态。
- 紧急修复也必须进入新补丁版本，例如 `v0.2.1`。
