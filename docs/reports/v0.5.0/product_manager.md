- 版本：`v0.5.0`
- 角色：产品经理

## 本版本目标

形成一次从白昼身份、三场战斗、休息、首领到三步晋升仪式的完整首章垂直切片。

## 依赖与证据

- 玩法：131 项基础、90 项成长、96 项路线测试通过。
- 数据层：150 项基础、59 项路线数据层测试通过；存档 v3 和 v1/v2 迁移已验证。
- UI：33 项基础、41 项成长、58 项路线 UI 测试通过；v0.5 美术实机审稿通过。
- 集成：73 项完整路线测试通过。
- 数值：1200 条固定种子路线完成；43 项路线契约测试通过。
- 自动化路线估算：14—25 分钟。

## 关键裁决

- 接受 ADR-0008：v0.5 目标调整为 15—30 分钟。
- 保留五节点和完整晋升作为本版本硬目标。
- 不通过提高敌人生命或增加重复战斗来凑时长。
- 100% 自动路线完成率可解释为首次晋升教学战，但必须作为试玩风险记录。

## 困难、候选方案与解决

| 困难 | 候选方案 | 当前决定 |
|---|---|---|
| 真实路线低于 30—45 分钟 | 加血量；临时加节点；调整首章范围 | 选择调整首章范围，长章节后移 |
| 两种休息几乎无取舍 | 隐藏选项；增加污染压力；重新设计资源交换 | 要求玩法前向补充真实可持续效果 |
| 首领第二阶段触发不稳定 | 提高全体生命；强化阶段反馈；记录风险 | 不以数值注水；保留风险并交由试玩反馈 |
| 仪式提示成本不可见 | UI 自行假设；核心快照增加只读字段 | 核心快照增加精确成本与回归 |

## 关闭结果

1. 休息选择已形成真实分布，1200 条路线中包扎 838 次、封锁回声 362 次。
2. `RitualSnapshot.hint_spirit_cost` 已提供给 UI，提示文案显示精确成本。
3. 全量回归与主场景退出码为 0。
4. UI 已完成 v0.5 美术实际界面审稿，美术未自行验收。
5. `v0.5.0` 已建立 Git 检查点并关闭。

- 基础玩法 131 项、成长 90 项、路线 98 项。

## 风险

- 自动化时长不是人工计时。
- 快速构筑可能低于 15 分钟，首次阅读和仪式失误可能高于 25 分钟。
- 正常路线压力偏低，后续章节需要更强内容而非更高血量。
