## 本版本目标

使用真实 `RouteEngine`、`BattleEngine` 和 `ProgressionEngine` 检查五节点短路线，而不是用聚合公式推断：

```text
首战 -> 精英战 -> 休息 -> 首领战 -> 三步晋升仪式
```

同时核对休息、首领阶段、成长、抽卡、升级和最终序列是否在固定种子下可复现。

## 采样方法

- 根种子：`20261108`
- 每个策略/身份组合：200 条完整路线
- 合计：6 个组合、1200 条路线
- 策略：激进、均衡、防守
- 身份：记者、医生
- 仪式熟练度假设：激进 82%、均衡 90%、防守 95%
- 每场战斗固定使用正式卡牌、owned deck、身份修正和升级后的内容端口
- 每场胜利后实际执行二选一奖励、可用祈愿和一次可支付的卡牌升级
- 休息选择使用当前状态的透明收益评分：生命、降低污染、下一战灵性上限分别按策略权重计值，被注视作为成本；不从 UI 读取答案，也不随机伪造选择

时间模型是规划估算，不代表人工计时：

- 每战斗回合：保守 0.55 分钟，宽松 1.0 分钟
- 每场战斗进入与结算：0.75 分钟
- 身份选择：0.5 分钟
- 休息选择：1.5 分钟
- 每步仪式：0.4 分钟
- 每次祈愿决策：1.2 分钟
- 每次升级决策：0.7 分钟
- 规划中值：`(保守 + 宽松) / 2`，用于检查 ADR-0008 的 15—30 分钟目标

## 发现与风险

### 1. 路线时长符合调整后的首章目标

六种组合的规划中值为 16.45—21.81 分钟，保守—宽松区间为 13.94—24.90 分钟，低于 30 分钟上限，
与 ADR-0008 的 15—30 分钟目标一致。激进路线保守下界略低于 15 分钟，但规划中值与宽松值均在目标内。

三场战斗平均合计仍只有 11—14 回合。后续若需要更长章节，应增加调查、事件或构筑决策，
不应通过虚增敌人生命或重复战斗制造时长。

### 2. 当前路线对策略玩家过于容易

六种组合的路线完成率均为 100%，终局生命普遍在 48—56 点，终局污染低于 1.2。首战教学定位可以接受高胜率，但精英与首领没有形成持续资源压力。

建议由玩法检查首领阶段和敌人组合，而不是由数值角色单纯提高攻击。当前首领两阶段平均只触发 1.03—1.65 次，说明部分路线在第二阶段前已经结束。

### 3. 两种休息已形成可解释取舍

新的收益评分模型中：

- 激进策略 200 条路线中 124 次选择 `rest.seal_echo`，偏向下一战灵性上限。
- 均衡策略 143 次包扎、57 次封锁回声，根据当前生命与污染切换。
- 防守策略 200 次全部包扎，优先即时生命安全。

1200 条路线不再出现单一选项垄断。封锁回声平均带来的被注视成本也已记录到终局被注视字段；
这证明两种休息形成了真实、可复现的差异，而不是仅靠 UI 或数值隐藏来控制选择。

### 4. 升级和抽卡仍会明显降低后半程压力

采样在每场战斗后都尝试可用祈愿和一次升级。均衡路线平均抽卡 7—9 次并完成接近 3 次升级，容易把后半路线变成确定性碾压。

当前 v0.5.0 保留节点间祈愿/升级。首次晋升路线允许较高完成率，但后续章节需要更强首领、
更严格的资源预算或减少节点间成长频率。该问题不改变本版本教学定位。
