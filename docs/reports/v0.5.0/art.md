## 构图说明

- 路线图固定五个编号安全区，不烘焙节点名称、奖励或状态文字。
- 休息场景左右各有一个主要交互区，中间保留污染/注视反馈和氛围焦点。

## UI 审稿请求

请 UI 在实际界面中检查：

1. 路线图五节点缩小后，当前、已完成、未到达状态是否清晰且不遮挡节点文字。
2. 休息场景左右选择区域与恢复/净化按钮是否冲突。
3. 首领“镜厅男爵”在战斗列中是否与普通敌人明显区分。
4. 三步仪式线索、仪式牌、提示和错误反馈是否压住中央证物。
5. 96px 路线图标缩到 24—32px、128px 仪式结果图标缩到 32—48px 时能否辨认。

UI 必须给出“通过、退回重做、仅需 UI 遮罩/裁切适配”结论。美术不得自行验收。

## 困难与选择

| 困难 | 候选方案 | 最终选择 |
|---|---|---|
| 固定路线没有真实地图结构 | 直线节点；弯曲羊皮纸路径；完整城市地图 | 五节点折线地图，只保留一条固定路线 |
| 首领容易与镜中猎犬混淆 | 犬形放大；人形礼服；多面镜厅剪影 | 人形礼服、礼帽、碎镜和手杖，保持独立轮廓 |
| 仪式牌若烘焙答案会限制 UI | 在牌面直接写姓名/顺序；只画证物符号 | 只画证物与几何标记，答案、选项和文字由玩法快照与 UI 提供 |
| 状态图标在小尺寸下差异弱 | 只换颜色；只换数字；使用不同轮廓 | 虚线圆、瞄准圆、对勾、成功封章、红色叉记 |
