## 美术审稿请求

请 UI 在实际游戏界面中检查：

1. 身份卡在身份选择区域缩小后，记者、医生、守墓人的职业轮廓是否可辨。
2. 祈愿背景中央卡位、按钮和抽卡结果区是否留出足够安全区。
3. 奖励档案背景三张纸页是否与奖励按钮和资源数值冲突。
4. 128×128 图标缩小到 32—64px 时，一级、二级、三级升级印章是否有可辨差异。
5. 卡背与现有牌组正面是否保持同一视觉体系。

UI 需在报告中标记“通过”“退回重做”或“仅需 UI 遮罩/裁切适配”。美术不得自行通过这些界面验收。

## 困难与候选方案

| 困难 | 候选方案 | 当前选择 |
|---|---|---|
| 三种身份容易都退化成相同剪影 | 仅换颜色；为每种身份增加专属职业道具；使用完全不同构图 | 为记者、医生、守墓人增加笔记本/眼睛、药瓶/听诊器、铲子/墓碑等职业轮廓 |
| 祈愿背景容易被抽卡结果覆盖 | 纯色底；中央留白祭坛；多卡片拼贴 | 中央祭坛留白，外围保留三分卡位，交由 UI 叠加卡牌 |
| 升级图标差异不清晰 | 只改数字；增加环形层级；使用不同金属印章 | 用 1/2/3 层环和印章复杂度表达等级，标签仍由 UI 渲染 |
