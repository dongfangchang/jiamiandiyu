# v0.3.0 角色报告入口

本目录按角色一人一文件，由对应角色独占维护：

- `gameplay_designer.md`
- `ui_designer.md`
- `numerical_designer.md`
- `local_backend.md`
- `product_manager.md`

每份报告至少包含：

- 版本、角色、任务、状态、修改文件
- 依赖和跨角色请求
- 已完成工作与真实验证结果
- 困难、至少一个候选方案与最终选择
- 根因修复、回滚或替换记录
- 风险、未决问题和下一步入口

角色不得通过聊天结论绕过本目录记录。满足 AGENTS.md 的同步触发条件时立即更新报告，重大接口或范围变化必须等待产品经理裁决。
