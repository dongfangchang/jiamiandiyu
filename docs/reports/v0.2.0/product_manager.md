## 接口冻结摘要

- `PlayCardCommand(card_instance_id, target_id?)` 与 `EndTurnCommand` 是战斗命令。
- UI 本地选择、取消和动画不是领域命令。
- `BattleSnapshot` 与 `BattleCommandResult` 是 UI 的唯一读取/结果入口。
- `BattleContentPort`、`BattleBalancePort`、`BattleRandomPort` 隔离文件、数值和随机数实现。
- 运行字段统一为 `corruption` 与 `attention`。
- 存档只在每日开始、战后领取结果、抽卡/升级/晋升提交后发生；不支持战斗中途恢复。

## 角色需求、困难与解决

| 角色 | 需求 | 困难 | 解决 | 移交 |
|---|---|---|---|---|
| 玩法 | 可测试、无 UI/文件依赖的战斗核心 | 自动战斗吸引力不足；契约未冻结 | 选择逐张出牌并冻结后实现 core | 压力时点与正式数据 |
| UI | 只读视图模型与命令边界 | 状态多且容易复制规则 | 独立页面 + 覆盖层 + 静态预览 | 正式战斗页接线 |
| 数值 | 可复现经济与战斗模拟 | 高胜率；压力规则实际无效 | 先调基础参数并上报时序问题 | 真实引擎采样 |
| 本地数据层 | schema、存档、RNG、装配 | 迁移顺序错误、类缓存冷启动失败 | 重构加载顺序；装配上移应用入口 | 正式内容 schema |
| 主协调者 | 环境、派工、集成 | shell 与重定向语法不匹配 | 精确清理并登记 BUG-0002 | 资源迁移和集成门 |

## 风险

- 谨慎慢速构筑 99.46% 聚合胜率偏高，ADR-0004 尚未在引擎和模拟中兑现。
- 当前没有正式内容数据，若直接进入 UI 接线容易产生测试夹具依赖或第二内容源。
- UI 角色报告仍含有旧字段，必须在生产接线前清理。
- 资源迁移若不一次完成，容易形成 `art/` 与 `assets/` 同名双份维护。
- 存档只支持检查点，UI 若不明确提示会误导玩家。
