# v0.8.0 / 本地数据层工作记录

## 状态

- 版本：`v0.8.0`
- 角色：本地数据层开发
- 状态：完成

## 完成内容

- 新增独立 `PlayerPreferencesService`，保存引导已读、全屏、界面缩放和减少闪烁偏好。
- 设置文件带版本号，缺失时使用默认值，损坏时保留原件并返回明确错误。
- 设置采用临时文件校验后替换。
- `AppBootstrap` 增加设置读取、保存和检查点备份恢复入口。
- 备份恢复先完整加载并迁移备份，再通过原子存档服务写回主槽。

## 验证

```text
PREFERENCES_TESTS_OK checks=16
APP_V07_INTEGRATION_OK checks=131
main scene --quit-after 5: exit 0
```

测试覆盖默认设置、保存读取、越界缩放归一化、损坏设置保护，以及真实主档/备份恢复。

## 风险

- 设置与游戏进度分开保存，因此恢复进度不会回退界面偏好。
- 若设置文件损坏，本次会话使用默认设置，但不会静默覆盖损坏原件。
