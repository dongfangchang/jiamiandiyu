## 本版本目标

让玩家在祈愿与升级页面直接理解资源用途、保底进度、升级成本和下一等级收益。版本只改善现有快照的表达，不改变经济、规则、存档或公共契约。

## 困难与方案

| 困难 | 候选方案 | 最终选择 | 理由 | 风险 |

| 祈愿页已有数字但缺少用途语义 | 改经济规则或补充现有字段解释 | 只补充 UI 说明和回退 | 保持 v0.22.0 的稳定经济与存档 | 小视口可能拥挤 |
| 升级页已有效果预览但成本信息分散 | 重做成长模型或整合卡片信息 | 复用现有快照，在卡片内并列显示 | 不复制规则，玩家能直接比较 | 异常快照需要安全文案 |
