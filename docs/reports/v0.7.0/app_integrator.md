## 已接入

- 启动与继续使用 v0.7 应用入口，并读取 v5 检查点。
- 身份选择后进入出战牌组页。
- 牌组页接收 `DeckSnapshot` 与成长等级，提交真实 `DeckCommand`。
- 合法八卡牌组确认后，首次路线和挑战使用该牌组。
- 编辑牌组会取消确认；只有重新确认后才能出战。
- 抽到的新卡进入收藏，可在下一次牌组编辑中加入。
- 卡牌升级效果由既有内容装饰端口进入下一场战斗。
- 挑战入口使用双挑战档案；第一挑战完成后刷新第二挑战解锁状态。
- 第二挑战使用独立路线变体和数据驱动修饰。
- 挑战奖励只入账一次；失败保留收藏、等级与牌组预设。
- 继续游戏恢复最近已确认节点，不恢复战斗中间状态。

## 困难与解决

| 困难 | 最终解决 |
|---|---|
| 旧 v0.6 入口仍加载固定内容 | AppController 使用 v0.7 专用启动和检查点接口 |
| 编辑牌组后可能带旧确认状态出战 | DeckCommand 修改后取消确认，由领域快照控制出战 |
| 第一挑战完成后第二挑战没有即时刷新 | 返回挑战档案时重新读取 v5 摘要和挑战快照 |
| 新卡进入祈愿/升级页后缺少缩略图 | UI 资源目录补齐八张 v0.7 卡面映射 |
