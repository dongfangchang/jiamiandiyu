- QA：规则边界、固定种子、UI 0/临界/触发状态。

## 决策

- 零费牌不累计，避免免费循环无限推进。
- 回响结束后清零，避免连环触发不可读。
- 结束回合清零，强调“本回合规划”。
- 连携仅存在于战斗运行时，不新增存档迁移。
- UI 初次放在顶部导致挤压，实机截图后移到右侧战斗记录区。
