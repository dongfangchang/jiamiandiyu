# v0.85.0 UI 报告

日记桌已接入宋体和新版贴图路径。标题与正文使用思源宋体 SC Regular，标题略加粗，页脚与旁注保留 Noto Sans。标题超出固定宽度时显示省略号，正文保留段落内的固定区域。旁注、长文和图片尺寸均不改变蜡封所在的布局。

左页优先使用 `assets/game/v0.85.0/diary/` 的独立竖幅图，按比例完整居中显示。旧横幅背景依旧覆盖画框。蜡封按可启、已阅、墨封选择独立透明贴图，缺图时仍可操作原样式。实际点击由投影热区处理，热区提供可访问名称、键盘焦点和悬停反馈，翻页过程中暂时停用。桌面已接入 `desk_wood.png`，缺图时沿用纸纹染色。纸张继续读取 `parchment_grain.png`。

沿用投影热区并单独绘制蜡封，避免让 SubViewport 内的贴图控件承担窗口输入。该方案保留旧版探针使用的 `WaxSealButton`，三个状态和任意尺寸贴图都共享同一命中矩形。
