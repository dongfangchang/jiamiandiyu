# 角色报告

每个版本每个角色一份报告：

```text
docs/reports/v0.1.0/product_manager.md
docs/reports/v0.1.0/gameplay.md
docs/reports/v0.1.0/ui.md
docs/reports/v0.1.0/balance.md
docs/reports/v0.1.0/local_backend.md
```

规则：

- 首次创建时复制 `docs/templates/agent-report.md`。
- 仅报告所有者更新事实部分。
- 产品经理可追加裁决，但不得改写角色的事实记录。
- 报告必须持续更新，不等到版本结束。
- 新版本使用新目录，不覆盖旧报告。
