# 日记章节主界面契约（v0.55 冻结）

> 替代路线树。载体：罗塞尔日记；结算驱动：阿勒苏霍德之笔(0-08)。  
> 本版切片：**A + 映射现有 `route.v028.first_stage` 节点**。完整 0-08 三分支演出、灵性擦拭进后续补丁。

## 1. 禁止 / 必须

- 禁止：路线树、节点卡片连线、「下一步 / 前往节点」、固定进度条强引导。
- 必须：交互入口仅为书页内线索文字；进度用墨渍 / 批注表达；0-08 笔仅结算演出，不常驻。

## 2. 结构

| 概念 | 说明 |
|---|---|
| 卷 volume | 一整本日记 = 一条主线卷（第一卷·小丑：廷根值夜者） |
| 页 page | 摊开双页中的一叶；单页 = 一组关联线索 |
| 线索 clue | 映射一个既有 `route` 节点；可调查时点文字进入战斗/休整/仪式 |

## 3. 线索三态

| 状态 | UI | 交互 |
|---|---|---|
| `locked` | 模糊 + 墨渍遮挡 | 不可点 |
| `available` | 清晰 + 淡暖金微光 | 点击 → 既有 `select_node` |
| `completed` | 原文保留 + 侧栏 0-08 批注 | 点击 → 只回看结局，不重进战 |

## 4. v0.55 切片边界

**做：**

1. 日记章节屏替换 `route_screen` 作为章节主界面。
2. 数据：`data/diaries/v0.55.0/` 把 v028 节点编成页/线索文案（底文 + 线索句）。

5. 0-08 笔：结算时短占位演出（文字生成），非完整镜头动画。

**不做（候选池）：**

## 5. 同页自由选择（本版策略）

- 目标规则：同页已解锁线索可自由挑选。
- v0.55：**同页内**将 `available` 扩成「该页所有未完成且已解锁」；页与页之间仍须本页主线线索全部 completed 才可翻到下一页（未完成页可回看，不可跳到未开页的可调查态）。
