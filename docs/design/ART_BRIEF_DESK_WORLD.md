# 书桌世界美术规格（ART_BRIEF_DESK_WORLD）

> 依据：`docs/architecture/EXPERIENCE_ARCHITECTURE.md`（ADR-0032）。  
> 风格基线：`ART_BRIEF_V085.md`（铜版 / 墨褐 / 烛光 / 纸木蜡），与已交付的日记八开、40 张卡、24 枚蜡封统一。  
> 落点：`art/assets/raster/desk_world/<object>/`；正式迁入由 coordinator 放到 `assets/game/desk_world/**`。

## 0. 通用规则（全部物件）

- **视角**：**正俯视（top-down，正交）**。物件平放在桌面上，透视由游戏内 3D 镜头提供。不画透视，不画桌面，不画投影。
- **背景**：透明 PNG（RGBA），边缘干净；可以沿用 `prop-keying` 技能，在纯色底上生成后再抠图。
- **光**：主光来自左上（烛台在桌面左上），暖色；高光和明暗都按这个方向。
- **阴影**：不画在物件 PNG 里。每个物件**另交**一张 `*_shadow.png`（灰度柔边，同尺寸），由引擎叠加。
- **文字**：插画里不写任何字（包括英文、数字）。游戏内文字由引擎排版。
- **分层**：有"开合"状态的物件，每个状态单独出图，尺寸相同、外轮廓对齐（便于引擎插值）。
- **尺寸**：标注的是交付尺寸；长边不超过 2048。
- **每个物件**附 `README.md`：尺寸、状态、来源 / 生成提示词、授权。
