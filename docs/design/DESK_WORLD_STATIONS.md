基准 **`station.diary`** = 现网日记镜头。其余为相对偏移设计值（实现可 ±5% 微调，但须保持日记 55–65% 构图不变）。

| 站位 ID | position | rotation_degrees | fov | 相对 diary | 构图意图 |
|---|---|---|---|---|---|
| `station.diary` | `(0.00, 1.61, 0.93)` | `(−59, 0, 0)` | **38** | 基准 | 开书主体；烛/羽笔仅余边 |
| `station.desk` | `(0.00, 2.40, 1.70)` | `(−50, 0, 0)` | **48** | +Y +0.79；+Z +0.77；fov+10 | 总览全桌六物件；日记合上居中 |
| `station.title` | `(0.00, 2.85, 2.55)` | `(−38, 0, 0)` | **42** | 更远更高；烛光弱 | 夜色远景；合书+书签纸条 |
| `station.dossier` | `(−0.70, 1.42, 0.92)` | `(−56, +22, 0)` | **34** | 左移推近档案 | 展开档案夹填满中景 |
| `station.cardbox` | `(0.78, 1.42, 0.95)` | `(−56, −20, 0)` | **34** | 右移推近卡匣 | 开匣+摊牌在桌面 |
| `station.altar` | `(0.72, 1.50, 0.55)` | `(−62, −14, 0)` | **32** | 右上、略俯 | 镜+粉笔圈居中 |
| `station.drawer` | `(0.00, 1.15, 1.25)` | `(−42, 0, 0)` | **40** | 降低、前移 | 拉开抽屉内卷宗 |

**镜头规则（对照 EXPERIENCE §4 T1）**

- 站位间一律 **T1**：0.45–0.6 s 缓入缓出；不淡出；目标 2D 在镜头到位前 **0.15 s** 淡入。
- `desk → *` 与 `* → desk` 共用同一位姿表；禁止硬切。
- 过渡期间路由器锁输入；禁止同步 `load()` 大纹理。

## 3. 各站位 2D 内容版式

2D 挂在 `StationLayer`，贴合物件（纸面 SubViewport 或桌面层），**不是**独立平面面板。字体：叙事用 `font.ink`（思源宋体）。

### 3.1 `station.title` — 书签纸条

```text
┌─ 合上的日记封面 (DW-05) ─────────────────┐
│                                         │
│              ┌──────────────┐           │
│              │ 存档摘要纸条  │ ← DW-04   │
│              │ 序列 · 章名  │   700×260 │
│              │ 「继续」蜡点  │           │
│              └──────────────┘           │
└─────────────────────────────────────────┘
  旁：烛台弱光 · 「新游戏」可落在第二张纸条或合书另一侧书签
```

- 内容：身份显示名（快照）、序列、当前章短名、最后存档时刻（可选一行）。
- 控件：蜡点/书签 = 继续；第二签 = 新游戏。禁止原生 Button 外观。
- **禁止**旧 `start_screen` 平面面板露出（H-03 热修精神延续到 X1）。

### 3.2 `station.dossier` — 两页档案

```text
┌──────── 左页 ────────┐ ┌──────── 右页 ────────┐
│ [相片框 DW-03]       │ │ 资源行（金/线索…）   │
│  身份插画            │ │ 局况：章 · 节点短名  │
│                      │ │ 当前卷 / 开 进度     │
│ 姓名（快照）         │ │ ─────────────────   │
│ 序列编号             │ │ 「确认身份」纸签     │
│                      │ │ （建档模式才显示）   │
└──────────────────────┘ └──────────────────────┘
         纸面材质：DW-02 公文纸纹
```

- 左：DW-03 框 + 身份图；姓名 ≤8 字；序列只读。
- 右：资源 / 局况 / 当前章——全部来自玩法快照字段，UI 不推算。
- 建档流：右页选项为身份候选纸签（非 OptionButton）。

### 3.3 `station.desk` — 悬停题签

- 常态：仅 3D 物件；**无**常驻 HUD 面板。
- 悬停物件 → 浮出 DW-07 题签（物件名 ≤6 字，如「日记」「档案」「卡匣」）。
- 按下：T1 推近对应站位；禁用/锁定态题签灰字+锁印（快照 `locked`/`available`）。
- 烛台悬停：「熄灭」→ T4 回标题（二次确认可用短纸签）。

### 3.4 `station.diary` — 现有左右页

- 维持 `DIARY_DESK_3D_BRIEF`：左插画 1260×1770；右题名≤10 + 笔迹≤60 + 蜡封。
- 返回上一级 = DESK（T1），不再「合书换屏」。
- 战斗入口：蜡封 → **T3** 墨迹 → `scene.battle`。

### 3.5 `station.cardbox` — 摊牌桌面

```text
开匣内槽 + 桌面上摊开的出战牌（只读卡面缩略）
残页袋 = 升级入口（点袋 → 升级纸签层，仍在本站）
确认纸签 / 返回 DESK
```

X1 可先占位网格；美术 DW-11/12 在 X2 批。

### 3.6 `station.altar` — 祈愿 / 仪式纸面

- 镜面区域揭示牌面；选项为纸签环绕粉笔圈。
- X2 前仪式可暂离桌；X2 起仪式模式并入本站。

### 3.7 `station.drawer` — 挑战卷宗

- 抽屉内 1～N 个文件夹（DW-22）；标签位空白，引擎写挑战名。
- 点开 = 卷宗内页（挑战说明），确认后进战。
- **产品冻结默认（2026-11-24）**：选挑战后 **T1→DESK→T3** 进战斗（避免抽屉内直接墨迹）。见 `docs/ACTIVE_PLAN.md` §0 · DW；`docs/reports/v0.88.0/product_manager.md`。日后改路径须产品开新裁决（建议 ADR）。

## 4. 进出过渡与输入状态

| 路径 | 过渡 | 时长要点 | 输入 |
|---|---|---|---|
| TITLE ↔ DESK | T1（远景↔总览） | 0.5 s | 过渡锁 |
| **新游戏：TITLE → DOSSIER** | **T1** | 0.45–0.6 s；**直达**，**不经** DESK 0.4 s 停留 | 过渡锁 |
| **建档后续：DOSSIER → CARDBOX → DIARY** | 各段 **T1** | 选身份确认后推近卡匣；确认牌组后推近日记第一卷第一开 | 过渡锁；建档中「返回」仍回 DESK（上一级规则），但首段入场不经过 DESK |
| DESK ↔ DIARY / DOSSIER / CARDBOX / ALTAR / DRAWER | **T1** | 0.45–0.6 s；2D 提前 0.15 s 淡入 | 过渡锁 |
| DIARY 开↔开 | **T2** 翻页 | 三开环预加载 | 翻页中只跟手，不点蜡封 |
| DIARY ↔ BATTLE（及回来） | **T3** 墨迹 | 裂蜡 0.5 + 切场景 + 墨退 0.4 | 全程锁 |
| 任意 → TITLE / 退出 / 加载失败 | **T4** 烛灭 | 0.6 s 暗下；唯一全黑 | 全程锁 |
| 继续：TITLE→DESK 停 **~0.4 s**→推荐站位 | T1 + 短停留 | 推荐站由 app `flow` 决定；**仅「继续」**，与新游戏分流 | 停留期间可提前点其它物件打断自动推近 |

### 新游戏建档流（对照 EXPERIENCE §3）

```text
TITLE ──新游戏 / T1──▶ DOSSIER（建档：选身份）
                         │
                         └─T1─▶ CARDBOX（选初始牌组）
                                   │
                                   └─T1─▶ DIARY（第一卷第一开）
```

- 与「继续」分流：继续先落 DESK ~0.4 s；新游戏**不**插入该停留。
- 建档中途若玩家触发「上一级」：仍服从「上一级 = DESK」（EXPERIENCE §3），再从 DESK 可点回档案/卡匣。

### 输入状态（物件 / 控件）

| 状态 | 视觉 | 交互 |
|---|---|---|
| 悬停 | DW-07 题签淡入；轻微提亮 | 可点 |
| 按下 | 题签压暗 / 蜡点下沉 | 触发 travel |
| 禁用 | 无题签或虚线题签 | 点击忽略 |
| 锁定 | 锁印 + 短原因 ID→UI 文案表 | 点击忽略或弹出只读纸签 |
