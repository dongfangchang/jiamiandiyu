# 正式立绘契约（v0.41 开工用 · v0.40 冻结）

> 本文件在 **v0.40.0** 由产品经理冻结。美术与主协调者在 **v0.41.0** 之前只读；  
> **禁止**在立绘制作期间改动下列稳定 ID、显示名或规则文案来源。若需改设计，必须先开新版并更新本表。

## 1. 原则（防割裂）

1. 卡面、档案、抽卡、战斗 HUD **共用同一** `definition_id` → 资源路径映射。
2. 显示名、规则短句以 `data/cards/v0.7.0/cards.json` + `TINGEN_CANON.md` 为准；立绘不另起故事。
3. 候选稿进 `art/**`；正式 PNG 仅由主协调者迁入 `assets/game/v0.41.0/**`（或当期版本目录）。
4. UI 只换路径与占位回退；不写规则分支。
