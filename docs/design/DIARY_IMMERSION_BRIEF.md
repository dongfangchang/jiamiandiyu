# 罗塞尔日记沉浸界面契约（v0.56 冻结）

> 题材：《诡秘之主》。核心载体：摊开的罗塞尔日记。  
> 交互媒介：阿勒苏霍德之笔（0-08）。  
> 目标：Godot 实时 UI / 可交互概念稿——重心在打开的书本；摒弃现代悬浮面板、生硬弹窗、规整菜单。  
> 与 `DIARY_CHAPTER_V055.md` 关系：v0.55 完成「日记替代路线树」切片；本文件由 **v0.56.0** 执行。

## 1. 一句话

玩家不是在点 UI 推进关卡，而是试图用 0-08 **撬动一本已经写好的命运记录**；日记有微弱自主意志，会抗拒、渗墨、低语。

## 2. 世界观墨迹语义（唯一视觉语言）

| 层 | 视觉 | 语义 |
|---|---|---|
| 罗塞尔原迹 | 褐色褪色旧墨 | 既定命运；已写好的原文 |
| 0-08 覆写 | 金色字迹 / 划痕 / 叠写 | 玩家行动后涂改命运；盖在原句上，不另辟空白区 |
| 侵蚀 | 半透明黑墨 / 霉斑蔓延 | 失控与污染；模糊、吞噬原文 |
| 墨封 | 墨水凝固、与纸融为一体 | 命运锁定；不可再涂改 / 不可强行翻离 |

多层可叠加：回看旧页时，不同时间的涂改痕迹错落可见。

## 3. 禁止 / 必须

**禁止**

- 常驻侧边索引栏、右上角数字状态条、模态弹窗菜单（批注回看尽量改为页内浮墨，不当系统 Dialog）
- 卡通亮色块、夸张惊悚 VFX、现代扁平控件堆叠
- 「下一步 / 前往节点」式强引导（继承 v0.55）

**必须**

- 所有状态、导航、进度优先表达为 **书页物理痕迹**
- 烛光昏暗暖侧光；纸张老旧纹理、水渍、折痕；低饱和、克制不安
- 背景简洁，画面重心是摊开的日记本
- 主路径禁止新增原生 `OptionButton`

## 4. 导航与翻页

### 4.1 页边墨迹索引

- 取消常驻 `IndexPanel`。
- 索引以淡浅墨迹批注藏在书页侧缘；指针靠近侧边区域时墨迹从纸缝渗出（朦胧），移开则隐去。
- 点击索引：笔尖拖出流动墨痕牵引视线 → 书页 **缓慢自主翻至** 对应段落（禁止瞬间跳转）。

### 4.2 翻页

- 主交互：拖拽书页角翻页。
- 兜底：底部低透明度翻页控件可保留。
- 未完成主线 / 墨封锁定时：强拖被 **书页抗拒回弹**，同步渗墨 + 低语氛围；不只用一行状态字拒绝。

## 5. 文字与状态

### 5.1 文本分层

1. 底层：罗塞尔褐色原文  
2. 中层：0-08 金色覆写 / 划掉 / 叠句  
3. 顶层：侵蚀黑墨遮罩（随污染蔓延）

回溯旧页须能看见历史涂改层（实现上可用叠层 Control / RichText 叠色 / 离屏缓存，不要求真 3D）。

### 5.2 状态 → 书页痕迹（移除独立数字栏）

| 资源 | 书页表达 |
|---|---|
| 生命 | 纸边磨损 / 血色旧渍或页角撕裂程度（可读但克制） |
| 灵性 | 页角淡金随手批注；越低越淡，耗尽则消失 |
| 污染 | 随机黑霉斑覆盖面积 ↑ |
| 注视 | 隐性：文字随指针轻微扭曲；值越高异动越明显；移开恢复 |

## 6. 演出

- 烛光缓慢晃动 → 书页明暗微变  
- 落笔：墨从落点晕开、逐字成型  
- 墨封：墨水凝固贴纸  
- 0-08 结算：笔扫过是覆写命运的镜头，不是系统横幅

## 7. 相对 v0.55 现状差距

| 项 | v0.55 现状 | 本契约 |
|---|---|---|
| 载体 | 双页日记 + 插画底 | 保留，强化「唯一舞台」 |
| 顶栏 | `HeaderParchment` + 生命/灵性/污染/注视数字 | 取消数字栏 → 书页痕迹 |
| 索引 | 常驻可开关 `IndexPanel` | 页边渗墨索引 |
| 翻页 | 底栏按钮 + 位移 tween | 拖页角为主；抗拒回弹 |
| 字迹 | 状态色差 + 墨渍贴图 + 笔改戳 | 褐/金/黑三层叠写 |
| 笔 | SVG 羽毛笔短演出 | 晕开书写 + 覆写原句 |
| 弹窗 | `AcceptDialog` 批注 | 页内浮墨批注 |
| 底栏 | 多按钮 + 状态句 | 极低透明兜底；文案尽量改页内低语 |

## 8. 建议分期（开版时裁剪）

**P0 — 去游戏壳**

- 隐藏/撤掉顶栏数字与厚顶底羊皮条；状态改页角批注 + 霉斑（可用现有 run_state 驱动 modulate/遮罩）
- 批注回看改为页内浮墨，去掉 AcceptDialog
- 底栏按钮降到极低透明；状态拒绝改渗墨回弹反馈（可先 tween + 音效）

**P1 — 导航语言**

- 页边渗墨索引（hover 显隐）
- 索引点击：墨痕牵引 + 慢翻（禁用瞬跳）
- 拖页角翻页原型

**P2 — 字迹三层**

- 原文褐 / 0-08 金覆写 / 侵蚀遮罩数据结构与渲染
- 历史涂改层在回看时可见

**P3 — 氛围抛光**

- 烛光晃动、落笔晕开、墨封凝固、注视扭曲 shader/轻位移
- 正式纸纹立绘替换程序 grain（美术）

## 9. 非目标（本契约亦不要求一次做完）

- 新卡、第二途径、路线树 UI  
- 完整 0-08 三分支叙事重写  
- 影视级纸张仿真 / 手写字体引擎  

## 10. 验收口径（开版后写入版本文档）

1. 1600×900 首屏：一眼是摊开日记，无明显「HUD 仪表盘」  
2. 不打开任何侧栏也能完成：读线索 → 调查 → 回页看金批/墨渍 → 翻页  
3. 污染/灵性变化可在书页痕迹上感知，无需读右上角数字  
4. 锁定翻页有抗拒回弹，不只靠一句灰字  
5. 探针：既有 `V055_*` 语义回归 + 新沉浸专项（hover 索引、三层字迹、无 Dialog）

## 11. 候选池交叉

- 晋升考核「信息前置 / 失败不灭章」可与本契约并行：守则写进日记褐墨原迹，答对后由 0-08 金笔覆写「已起誓」——仍是书页语言，不是新面板。
