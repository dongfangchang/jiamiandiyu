# 书桌世界过渡线框（T1–T4）

> 对照 `EXPERIENCE_ARCHITECTURE.md` §3–§4。实现在 UI-X1；本文件只定语义。  
> AR-04 补丁：新游戏 TITLE→DOSSIER 直达。

## 状态机（简图）

```text
TITLE ──T1（继续）──▶ DESK ──T1──▶ DIARY / DOSSIER / CARDBOX / ALTAR / DRAWER
  │                     ▲                    │
  │                     └──── 返回（上一级）───┘
  │
  └──T1（新游戏）──▶ DOSSIER ──T1──▶ CARDBOX ──T1──▶ DIARY
                         │              │
                         └──── 上一级仍回 DESK（建档中途）──▶ DESK

任意站位 ──T4 烛灭──▶ TITLE

DIARY ──T2──▶ 下一开
DIARY ──T3──▶ BATTLE ──T3──▶ DIARY
```

## 规格表

| ID | 名称 | 触发 | 视觉 | 输入 |
|---|---|---|---|---|
| T1 | 镜头移动 | 同世界站位切换；TITLE↔DESK；**TITLE→DOSSIER（新游戏）** | 0.45–0.6 s 位姿插值；**不淡出**；目标 2D 提前 0.15 s 淡入 | 锁 |
| T2 | 翻页 | 日记开↔开 | 三开环；叶片正=当前右，背=下一左；落定只换引用 | 跟手拖；不点蜡 |
| T3 | 墨迹门槛 | 书桌⇄战斗/仪式 | 蜡裂→墨晕 0.5 s→切场景→墨退 0.4 s | 锁 |
| T4 | 烛灭 | 回标题 / 退出 / 加载失败 | 焰灭→0.6 s 暗下；**唯一全黑** | 锁 |

## 继续流（特殊）

```text
TITLE ─T1→ DESK（停留 ~0.4 s，档案夹可一眼认身份）
         └─T1→ 推荐站位（app/flow 决定）
玩家可在 0.4 s 内点击其它物件，打断自动推近。
```

## 新游戏建档流（特殊 · 与继续分流）

```text
TITLE ─T1→ DOSSIER（建档选身份）     ← 直达，不经 DESK 0.4 s
         └─T1→ CARDBOX（选初始牌组）
                └─T1→ DIARY（第一卷第一开）
```

建档中途「上一级」→ DESK（统一规则）；首段入场路径本身不经过 DESK。

## 禁止

- 硬切
- T4 以外的全黑淡入淡出
- 过渡帧露出另一站位 2D 残留
- 过渡帧同步 `load()` 大纹理
