# Agent Memory（角色记忆与草稿）

每个固定角色一个子目录：

```text
<role>/
  journal.md     # 时间线 + Retro
  drafts/        # 未晋升技能草稿
```

**待办任务**：`.cursor/agents/<role>/tasks.md`（先立任务后执行；不放在本目录）。

协议：`.cursor/agents/_meta/SKILL_LOOP.md`、`_meta/TASKS_FORMAT.md`  
技能成品：`.cursor/skills/`  
工具配方：`.cursor/agents/_meta/TOOL_REGISTRY.md`
