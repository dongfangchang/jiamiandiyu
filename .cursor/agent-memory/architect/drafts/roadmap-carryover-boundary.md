- status: draft
- 来源: AR-01 / AR-02（2026-11-24）
- 适用: 架构师在 Rn 关版后 / Rn+1 开版前

## 步骤

1. 打开关版文档「遗留」列表（如 `versions/vX.md` §4.1）。
2. 逐条对 ROADMAP 既有 ID；对得上 → 在该条目补注来源；对不上 → **新开最小条目**（勿口头债）。
3. 不立项的写「—」+ 一句话理由（生成物 / 非运行时）。
4. 阶段边界评审 = 四件套写进 ROADMAP：行为不变句、黄金回放更新权属、文件×单一负责人勾选表、体验框架禁令（若适用）。
5. 报告摘要进 `docs/reports/<ver>/architect.md`；tasks done + journal Retro。

## 反例

- 把死代码「顺手」塞进别的大条目而不写 ID → 无人认领。
- 各轨道自行 `--update` 黄金回放 → 语义 diff 不可审计。
