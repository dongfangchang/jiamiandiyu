# Draft · 书桌站位设计稿评审清单

状态：draft  
来源：AR-04（2026-11-24）  
适用：评审 `DESK_WORLD_STATIONS` / 同类 EXPERIENCE 站位稿

## 清单

1. **空间**：六物件 + 七站位 ID 与 EXPERIENCE §2 一致；日记开书 55–65% 视口宽有数。
2. **镜头**：以现网 diary 为基准；其余站相对偏移 + fov；允许 ±5% 实现微调。
3. **过渡完备**：T1–T4 齐全；**继续**（DESK 0.4 s→推荐站）与**新游戏**（TITLE→DOSSIER→…）都有表行；禁硬切 / 非 T4 全黑。
4. **AABB**：每个锚点×足迹互不重叠（含附属物：羽笔、残页袋、开态档案）。
5. **§8 归属**：每个 2D 块能答「哪物件的哪站位」；无平面面板 / OptionButton / `add_background` 设计。
6. **分期**：X2/X3 物件可占位，但勿当作本轮精审通过。

## 失败模式

- 只审镜头、不审俯视足迹 → 漏道具碰撞。
- 只审「继续」流、漏「新游戏」直达 DOSSIER → travel() 状态机缺口。
