# v0.7.0 牌组内容

`decks.json` 定义 8 张唯一卡牌的牌组规则、16 张卡牌目录顺序和三套初始预设。

- `deck.preset.ward`：初始合法牌组，全部由 starter 卡组成，包含两张伤害终结牌和三张防御牌。
- `deck.preset.oracle`：灵性与抽牌方向，保留两张防御牌和两张终结牌，需要祈愿解锁部分卡牌。
- `deck.preset.burst`：凶兆与高伤害方向，需要祈愿解锁部分卡牌。

牌组只保存稳定 `definition_id`，不保存显示名、卡牌金额或资源路径。

本地数据层需要建立 `DeckContentPort` 适配器与 schema，并校验：

- 默认预设存在且合法。
- 三套预设 ID 唯一。
- 目录卡牌全部存在。
- 保存预设只接受 8 张唯一且已拥有的卡牌。
