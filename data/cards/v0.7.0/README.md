# v0.7.0 占卜家卡池

本目录是占卜家战斗卡包，v0.13.0 扩展后共 20 张唯一卡牌。

- `cards.json`：20 张卡牌定义，是当前版本卡牌效果与金额的唯一事实源。
- `progression.json`：身份、初始收藏、祈愿池、奖励和升级定义。

新增 8 张卡围绕三个方向：

- 防御与稳定抽牌：守夜圆环、提灯步。
- 灵性与牌序：灵性预感、镜中记忆、第二视觉。
- 标记与爆发：命运回声、穿刺凶兆、棺钉。

初始拥有 10 张卡，其中包含 2 张可靠伤害牌、3 张防御牌和标记起手牌，默认“守夜档案”牌组可立即确认出战。祈愿池中的每张卡都具有升级定义。

本地数据层需要：

- 新增 v0.7 cards/progression schema。
- 将默认 cards、progression 路径切换到本目录。
- 保持卡牌金额只在 `cards.json`，概率与经济仍在 `data/balance/**`。
