# 假面低语（本地原型）

单人、离线的《诡秘之主》同人卡牌原型。v0.3.0 已形成可玩的单场教学战；当前正在开发 v0.4.0 的身份、奖励、抽卡和升级短循环。

## 已安装环境

- Godot `4.7.2-stable`，标准版，GDScript。
- 便携编辑器路径：`.tools/godot-4.7.2/Godot_v4.7.2-stable_win64.exe`
- 下载文件已通过 Godot 官方 `SHA512-SUMS.txt` 校验。
- Git 已可用。

双击 `open-editor.cmd` 即可用 Godot 打开本项目。

主场景：`res://src/app/app_root.tscn`。启动后可开始新游戏、进行正式双敌人战斗、查看胜负并读取战后检查点。

## 目录

- `art/`：美术方向、资产清单、SVG 源文件与生成脚本。
- `assets/game/`：Godot 运行时正式 PNG。
- `project.godot`：Godot 项目配置。
- `docs/`：产品章程、协作协议、架构契约、版本记录、角色报告和 Bug 记录。

## 当前开发基线

- v0.3.0：已关闭；单场逐张出牌教学战、战后保存和继续读取可玩。
- 当前版本：`v0.4.0`，主题为“白昼身份、战后奖励、灵界祈愿抽卡与卡牌升级”。
- 所有参与开发的智能体必须先阅读 `AGENTS.md` 和 `docs/CURRENT_VERSION.md`。
- 每个版本使用独立文档，不覆盖历史版本。
- UI 与美术保持独立角色，所有正式美术必须经过 UI 实际界面审稿。

## 当前美术样板

- 标题画面。
- 记者、医生、守墓人三张人格牌。
- 窥视者之眼、无面遗嘱两张封印物牌。
- 哭泣的房客、烛焰飞蛾、镜中猎犬三张独立敌人图。
- 8 张无文字卡面、专用战斗背景与 12 个状态图标。

详细风格与提示词规范见 `art/ART_DIRECTION.md`。
