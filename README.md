# 假面低语（本地原型）

单人、离线的《诡秘之主》同人卡牌游戏。v0.10.0 已包含首次引导、卡组构筑、抽卡升级、首次序列晋升、双挑战、战斗连携与灵性回响，并通过破坏性 QA 与发布门禁。

## 已安装环境

- Godot `4.7.2-stable`，标准版，GDScript。
- 便携编辑器路径：`.tools/godot-4.7.2/Godot_v4.7.2-stable_win64.exe`
- 下载文件已通过 Godot 官方 `SHA512-SUMS.txt` 校验。
- Git 已可用。

双击 `open-editor.cmd` 即可用 Godot 打开本项目。
双击 `play.cmd` 可直接启动当前可玩版本。

`play.cmd` 仍依赖项目内 `.tools/` 中的 Godot；下面生成的独立构建不依赖编辑器、`.tools/` 或网络。

生成独立 Windows 构建：

```powershell
.\build-windows.ps1
```

构建输出为 `build\windows\MaskWhispers.exe`，运行时不需要 Godot 编辑器或 `.tools/`。构建会复制到项目目录外启动验证，退出码应为 `0`。

如果旧构建仍在运行，Windows 会锁定 `MaskWhispers.exe`。关闭游戏后重新运行构建脚本即可更新；本轮同时保留了已通过项目外启动验证的版本化文件 `build\windows\MaskWhispers_v0.10.0.exe`。

游戏检查点保存在：

```text
%APPDATA%\Godot\app_userdata\假面低语（本地原型）\
```

主检查点在 `saves/checkpoint.json`，上一份备份为 `saves/checkpoint.json.bak`；设置与引导状态位于 `preferences.json`。主菜单可直接恢复备份；恢复前会再次校验备份，并把被替换的主档保留为 `checkpoint.restore-old.json` 供诊断。

主场景：`res://src/app/app_root.tscn`。启动后可查看新手引导与设置，选择身份和八卡牌组，完成首次路线、双挑战、奖励、祈愿与升级。

## 目录

- `art/`：美术方向、资产清单、SVG 源文件与生成脚本。
- `assets/game/`：Godot 运行时正式 PNG。
- `project.godot`：Godot 项目配置。
- `docs/`：产品章程、协作协议、架构契约、版本记录、角色报告和 Bug 记录。
