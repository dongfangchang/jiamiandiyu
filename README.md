# 假面低语（本地原型）

单人、离线的《诡秘之主》同人卡牌原型。项目目前处于环境与美术预生产阶段，尚未开始实现游戏主循环。

## 已安装环境

- Godot `4.7.2-stable`，标准版，GDScript。
- 便携编辑器路径：`.tools/godot-4.7.2/Godot_v4.7.2-stable_win64.exe`
- 下载文件已通过 Godot 官方 `SHA512-SUMS.txt` 校验。
- Git 已可用。

双击 `open-editor.cmd` 即可用 Godot 打开本项目。

## 目录

- `art/`：美术方向、资产清单、SVG 源文件、PNG 预览与生成脚本。
- `art/preview/contact-sheet.html`：浏览器中查看现阶段美术样张。
- `project.godot`：Godot 项目配置。
- `docs/`：产品章程、协作协议、架构契约、版本记录、角色报告和 Bug 记录。

## 当前开发基线

- 当前版本：`v0.2.0`，主题为“规则与接口冻结”。
- 所有参与开发的智能体必须先阅读 `AGENTS.md` 和 `docs/CURRENT_VERSION.md`。
- 每个版本使用独立文档，不覆盖历史版本。
- 当前状态尚未实现游戏主循环，正在冻结玩法、UI、数值和本地数据层接口。

## 当前美术样板

- 标题画面。
- 记者、医生、守墓人三张人格牌。
- 窥视者之眼、无面遗嘱两张封印物牌。
- 提灯追猎者敌人立绘。
- 晋升试炼场景与状态图标表。

详细风格与提示词规范见 `art/ART_DIRECTION.md`。
