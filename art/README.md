# 美术资源使用说明

## 0. 统一卡牌美术框架（现行标准）

> **目标**：同尺寸、同信息区、同卡框、同稀有度位置；换卡只换「插画 + 少量类型色点」。  
> **观感**：卡面不挤、卡框不抢、信息能读；**色调跟现网桌面日记一致，不是漂白铜版报**。  
> **文字**：名称 / 费用 / 数值 / 描述 **一律不烘焙进图**，由 Godot UI 绘制（与 `ART_DIRECTION.md` 一致）。

样例图：`art/assets/raster/v0.85.0/card-framework/`  
色板与风格总纲：`ART_DIRECTION.md` + 现网 `src/ui/mask_ui_theme.gd` + 参考 `样板.jpg`

#### 0.0 与游戏画风对齐（色温）

现网不是「满卡米色线稿」，而是 **深桌面 + 烛暖金 + 蜡封红 + 雾冷灰**，纸只作可读底板：

| 角色 | 色 | 用在卡上 |
|---|---|---|
| 桌面/外缘 | `#11120d` / `#1c1b15` | 卡外缘可偏深褐皮边，衬出纸心 |
| 旧纸可读区 | `#D8C29A` → `#AF9165` | 标题带、效果板；**不要整卡同一亮米色** |
| 暗金（烛/可用） | `#B99750` → 高光可到 `#E0C47A` | 细框、类型点、稀有环；要有一点「烛光」 |
| 蜡封/危险 | `#7A2828` → 蜡面可略暖赤褐 | **稀有度章优先做成蜡封质感**（对齐样板「进入」印） |
| 冷雾 | `#788079` + 蓝灰雾 | **插画窗内**空气感，打破一片褐 |
| 骨白字底 | `#E8DFC9` | 效果板，保证字对比 |

**禁止**：整卡单色 sepia；插画也画成浅纸线稿导致和框糊成一块。  
**插画窗**应接近日记左页叙事画：暗环境、一处暖光、可辨主色，而不是再印一张浅铜版。

### 0.1 画布与分区（600 × 840）

比例约 **5:7**（与现网验收样张一致）。像素坐标原点在左上。

```
┌──────────────────────────────────────┐  y=0
│  [A] 顶栏  类型点 · 名称位 · 编号     │  0 → 56
│  [B] 标题带（大字安全区）              │  56 → 156
│  [C] 插画窗 ART WINDOW（唯一焦点）     │  164 → 554
│      内边：x=44..556  (=512×390)     │
│  [D] 分隔线                           │  y≈569
│  [E] 效果板 EFFECT PANEL              │  589 → 720
│  [F] 底栏  费用 · 数值槽 · 稀有度章    │  720 → 820
│  外框与四角折饰（全卡共用）            │  边距 18–24
└──────────────────────────────────────┘  y=840
```

| 区 | 矩形 (x,y,w,h) | 职责 | 换卡时 |
|---|---|---|---|
| **纸底** | 全画布 | 旧纸色 `#D8C29A` + 轻污渍/暗角 | **共用** |
| **外框** | 内缩 ~18–24px 的双细线 + 四角折饰 | 秩序感；**细、哑光暗金**，禁止厚发光 | **共用骨架**；稀有度只改线复杂度 |
| **A 顶栏** | `(44,20)–(556,56)` | 左：类型徽（身份/技能/封印物）；右：档案编号 `00/00` | 只换徽标图形与编号 |
| **B 标题带** | `(44,64)–(556,148)` | 卡名（UI 字）+ 一行短副题位 | **UI 填字**；图上留空 |
| **C 插画窗** | `(44,164,512,390)` | **唯一视觉焦点**；无字、无第二主体 | **每卡替换插画** |
| **E 效果板** | `(44,589,512,116)` | 淡骨白底 `#E8DFC9`≈22% 透明感；UI 写效果 | **共用底板** |
| **F 底栏** | `(44,724)–(556,812)` | 左费用圆；中 2–3 数值槽；**右下稀有度章（固定锚点）** | 数值 UI；稀有度换章纹 |

**安全边**：左右各 **44px**；插画勿贴窗边（建议窗内再留 ≥12px 呼吸）。

### 0.2 图层栈（制作 / 换卡）

从下到上，固定 7 层：

| # | 层 | 文件建议 | 每卡是否变 |
|---|---|---|---|
| 1 | `paper_base` | 纸底+污渍 | 否 |
| 2 | `art` | 512×390（或 512×400 裁进窗）无字插画 | **是** |
| 3 | `frame_chrome` | 双细线框 + 四角折饰 | 否（稀有用变体） |
| 4 | `type_pip` | 顶栏类型点 | 是（3 套即可） |
| 5 | `effect_panel` | 效果区底纹 | 否 |
| 6 | `seal` | 右下蜡封（稀有度壳 × 机制芯，见 §0.3） | 组合选用 |
| 7 | UI 文字 | Godot | 是 |

**换一张新卡最少动作**：换第 2 层插画 + 选对顶栏类型点 + 组合一枚蜡封 + UI 填「短句」。

### 0.3 蜡封系统（双通道 · 同锚点）

锚点：**右下**，圆心约 `(508, 768)`，外径约 **56–64px**（手牌缩小时仍认色/形）。  
**禁止**：彩虹顶栏、日记「进入」文案、把长说明刻进章面。

蜡封 = **外壳（稀有度）** × **芯纹（机制）**。两套正交，美术只做矩阵拼装，不每卡手绘新章。

#### 0.3.1 外壳 = 稀有度（色 + 外轮廓）

| 稀有度 | 蜡色 | 外轮廓 | 框线联动 |
|---|---|---|---|
| `common` | 褐蜡 `#7A2828`～赤褐 | **圆**，单环 | 单层暗金细线 |
| `uncommon`（预留） | 墨绿蜡 / 冷青灰蜡 | **圆**，单环+细齿边 | 单层线 + 角饰略多 |
| `rare` | 暗金蜡面 `#B99750` 或赤蜡+金边 | **圆**，**双环** | 双层线 + 角饰密一档 |
| `mythic`（预留） | 近黑蜡 + 金裂 | **椭圆竖章**或破边圆 | 双层 + 微裂纹（仍细，不发光） |

一眼靠 **色+环数** 认稀有；形状变化要克制，避免和芯纹抢读。

#### 0.3.2 芯纹 = 机制标签（图案，不写字）

压印在蜡心，**线稿剪影**，缩到 24px 仍可辨：

| 机制 | 芯纹 | 典型用途 |
|---|---|---|
| `attack` | 斜刃 / 矛尖 | 直伤、射击 |
| `defense` | 盾面 / 墙砖横线 | 护盾、灵性之墙 |
| `ritual` | 烛芯+小环 / 三格印 | 仪式准备、驱邪 |
| `divination` | 摆坠 / 单眼 | 灵视、占卜、预感 |
| `support` | 双折页 / 手掌简符 | 抽牌、支援、治疗向 |
| `curse` | 裂印 / 倒钩 | 污染、封印物反噬（慎用） |

**组合例**：银质匕首 = `common` 褐圆壳 + `attack` 斜刃芯（兼仪式可用第二小点在规则里写，章面只选主标签，避免一章双纹）。

资源建议：`art/assets/raster/v0.85.0/seals/` 下按  
`seal_{rarity}_{mechanic}.png`（透明底 128×128）交付，UI 运行时叠到锚点。

样张：`card-framework/seal-matrix-sheet.*`（一览表）。

#### 0.3.3 顶栏类型点（与蜡封分工）

蜡封管「稀有 + 战斗机制」；顶栏左点管「内容大类」，互不替代：

| 类型 | 点形状 | 插画倾向 |
|---|---|---|
| 身份 | 小方印 | 肩上胸像 |
| 技能 | 小圆点 | 单一象征 |
| 封印物 | 小菱 / 环 | 单件证物 55–70% |

点 ≤28px；暗金或墨黑。

### 0.4 文案分层：短句上卡，长文进档案（不抢画框）

卡面 **600×840 装不下** 规则全文 + 风味 + 出处，也不该靠拉高效果板去挤插画。

| 层 | 放哪里 | 容量 | 谁画 |
|---|---|---|---|
| **L0 扫读** | 卡面 [E] 效果板 | **1～2 行**（约 ≤28 字）主效果摘要 | UI 字 |
| **L1 战斗必要** | 同一板或费用旁小标 | 费用、伤害/护盾数字、1 个关键词 | UI |
| **L2 完整规则** | **检视层**（点选/长按/右键） | `rules_text_zh` 全文 | UI 面板，**不改卡图** |
| **L3 风味/出处** | 检视层下半或第二页签 | `flavor_text_zh` / `source_zh` | UI |

**检视层怎么进画面（现行推荐 · 弹层，不翻页）**：

手牌/牌阵上的卡 **永远保持短句框架**；要看细则时：

1. **打开**：点选已选中的手牌再点一次，或专用「检视」热区 / 长按（具体键位由 UI 定，美术不绑死）。  
2. **形态**：**居中弹层（modal）** + 半透明暗角，盖在战斗桌之上。  
   - **不是**把卡翻到背面看说明（背面留给统一卡背）。  
   - **不是**砍矮插画窗塞长文。  
   - **不是**再叠一枚蜡封/稀有章（章只活在卡面右下；检视里纯文字+缩略图）。  
3. **关**：点暗角空白、关闭钮或 Esc。  
4. **板内结构**（羊皮档案条，可滚动）：

```
┌─ 检视弹层 ─────────────────────────────┐
│  [缩略插画]   卡名 · 费用 · 类型标签      │
│               ─────────────────         │
│               完整规则（可滚动）         │
│               风味句                     │
│               出处一行                   │
│                          [合上]         │
└─────────────────────────────────────────┘
```

- 手牌继续只显示 L0+L1；L2/L3 **只出现在弹层**。  
- 数据字段：`description_zh`→L0，`rules_text_zh`→L2，`flavor_text_zh` / `source_zh`→L3。

**银质匕首示例**：

- L0 卡面：`造成3点伤害并获得1层仪式准备。`  
- L1：费用 `1`。  
- L2 弹层：完整 `rules_text_zh`（含对灵体额外伤害）。  
- L3 弹层：`黑夜女神对应的金属是纯银。` + 出处。

### 0.5 可读与「不挤」硬规则

1. **一个焦点**：插画窗内只允许一个主符号/人物。  
2. **框不抢**：线宽视觉 ≤2px @600；无厚发光。  
3. **字不进插画 PNG**；章面不写汉字。  
4. **长文不进卡面**：超过 2 行进检视层（§0.4）。  
5. **留白**：区与区 ≥8px；窗内主体有空气。  
6. **手牌缩小**：插画轮廓 + 蜡封色形在 ~58px 高可辨。  
7. **强调色**：单卡外观最多两色强对比（金 / 蜡红）；机制靠芯纹不靠彩虹。

### 0.6 交付清单（单卡）

| 交付 | 尺寸 | 备注 |
|---|---:|---|
| 插画 `art` | **512 × 390** | 无字、无框 |
| 蜡封 | 选用 `seal_{rarity}_{mechanic}` | 128×128 透明底 |
| （可选）完整验收样张 | 600 × 840 | 仅审稿；L0 假字即可 |
| 文案 | 数据字段 | 短句→卡面；长文→检视 |

---

### 0.7 反例（不要做）

- 每张卡自制一种完全不同的外框比例。  
- 稀有度改到左上/顶条彩虹，导致锚点错位。  
- 插画烘焙卡名、费用、长描述；或把「进入」印在卡章上。  
- 为塞长文把插画窗压到一半以下。  
- 一枚蜡封上刻两个以上机制芯纹 + 一串字。  
- 厚金属浮雕框盖住插画上 1/3。

## 1. 目录

- `ART_DIRECTION.md`：视觉方向、色板、提示词。
- `ASSET_MANIFEST.md`：资产与来源记录。
- `assets/svg/`：可编辑矢量源（含历史版本卡面）。
- `assets/svg/templates/card-frame.svg`：早期完整验收框（与 §0 同画布，可作对照）。
- `assets/raster/v0.85.0/`：栅格源（日记插画、`props/` 拆件、`card-framework/` 样例）。
- `../assets/game/`：Godot 运行时正式 PNG（唯一）。
- `tools/`：各版本生成脚本。

## 2. 重新生成（历史脚本）

在项目根目录：

```powershell
node art/tools/generate_art.mjs
node art/tools/generate_v030_art.mjs   # … 以及 v040 / v050 / v060 / v070
```

脚本使用 Node 内置模块；旧版 PNG 规格见各 `render-manifest.json`。

## 3. PNG 导出规格（摘要）

| 类型 | 画布 |
|---|---:|
| 卡牌完整样张 / 框 | **600 × 840** |
| 卡面插画窗 | **512 × 390**（安全裁切） |
| 敌人 | 900 × 900 |
| 标题 / 仪式 | 1600 × 900 |
| 状态图标 | 64 × 64 |

牌阵缩略可另出 256 × 358。

## 4. 接入 Godot

- 运行时：**插画 + 共用框层 + UI 字**；不要用带烘焙字的完整 JPG 当唯一资源。  
- 卡框可做九宫格/分层；稀有度章与类型点用小图或矢量叠在固定锚点。  
- UI 实机审稿通过后，才算正式卡面交付完成。
