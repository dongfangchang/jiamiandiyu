## 共同要件

- 镜头相对标题页**略推近**，同房同桌同烛同书锚点。
- 桌面可见：日记、档案夹/皮面档案、卡匣、祈愿台（镜 + 三烛 + 粉笔圈）、抽屉。
- 桌角**索引卡**文字入口：日记 / 档案 / 卡匣 / 祈愿 / 卷宗 / 熄烛（菜单 ≥22px，对比度 ≥4.5）。
- 每一方案有一项**悬停**高亮，对应物件应被烛光提亮（概念示意）。

## 三方案差异

| 方案 | 构图思路 | 悬停 | 一句话差异 |
|---|---|---|---|
| **1** | 略俯视，物件横向静物铺开，抽屉沿露出 | 「日记」 | 俯角横铺、信息最全，偏「总览说明书」 |
| **2** | 斜透视，保留书架 + 雨窗进深 | 「祈愿」 | 同房锚点最强，偏「标题页推近后的活房间」 |
| **3** | 更近更密，索引卡左前大卡 | 「档案」 | 贴桌微距感，偏「俯身操作」 |

## 实现方式建议（签字后由架构师裁定）

| 方案 | 推荐路径 | 说明 |
|---|---|---|
| 1 | **分层绘制**（远景杂物 / 桌面静物 / 前景索引卡）+ 弱程序烛光 | 俯角静物密度高，纯 3D 易「塑料铺货」 |
| 2 | **分层绘制**为主；雨窗/书架可用 DQ-01 类背景板 | 与 title candidate 同房最顺；Mobile 不做真体积雾 |
| 3 | **分层绘制** + 近景接触阴影（DQ-06 族） | 推得近，几何精度要求高；3D 程序仅作布局探针 |

共同不建议：整屏纯 3D+PBR 当最终画面（ADR-0037 D3：实现服从目标帧）。

## 选型提示（给用户）

- 要一眼看清所有入口物件 → **方案1**
- 要和标题页/日记页「同一间书房」感最强 → **方案2**
- 要更沉浸、更贴桌的操作感 → **方案3**
