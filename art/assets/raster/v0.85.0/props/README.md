# 样板拆件（props）— 供基础模型 / UI 贴图

依据根目录 `样板.jpg`（副本：`../reference/样板.jpg`）拆出的单件资产。  
深炭底便于抠图；**尚非**正式 `assets/game` 交付。

| 文件 | 元素 | 说明 |
|---|---|---|
| `prop-candle` | 烛台 / 蜡烛 | 滴蜡柱烛 + 浅托盘 |
| `prop-wax-seal` | 蜡封印章 | 「进入」压印蜡块 |
| `prop-desk-wood` | 桌面木纹 | 满幅材质板 |
| `prop-bookmark` | 书签缎带 | 酒红燕尾带 |
| `prop-quill-pen` | 羽笔 | 样板同风格补件（样板图内不明显） |
| `prop-inkwell` | 墨水瓶 | 同风格补件 |
| `prop-open-journal` | 打开的日记本 | 空白左右页，无 UI 字 |
| `prop-parchment-sheet` | 单页羊皮纸 | 空白纸张材质 |
| `prop-corner-ornament` | 页角花饰 | 标题框线稿角 |
| `prop-status-tokens` | 状态印四联 | 可用/曾失败/静默/归藏 |
| `prop-token-available` | 印·可用 | 金星罗盘 |
| `prop-token-failed` | 印·曾失败 | 银荆星 |
| `prop-token-silence` | 印·静默 | 银角符 |
| `prop-token-archive` | 印·归藏 | 银涡旋 |

每项同时有 `.jpg`（生成原稿）与 `.png`（管线用）。
